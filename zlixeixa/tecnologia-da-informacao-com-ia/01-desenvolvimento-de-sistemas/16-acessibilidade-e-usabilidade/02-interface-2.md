# Fundamentos de Interface e Acessibilidade Digital

## 1. Interface e Experiência do Usuário
- Interface do Usuário (UI) foca especificamente nos componentes visuais e interativos que compõem um sistema.
- Exemplos de elementos de UI incluem botões, ícones, layouts, cores e a tipografia escolhida para a aplicação.
- Experiência do Usuário (UX) trata da percepção e das emoções despertadas no usuário durante sua interação com o sistema.
- A UX abrange a jornada completa do usuário, cobrindo desde o contato inicial até a finalização da tarefa pretendida.

## 2. Elementos Visuais e Textuais
- Elementos visuais: compreendem o uso de cores, tipografia, imagens, ícones e o gerenciamento do espaçamento entre os componentes;
- Elementos textuais: envolvem a busca pela clareza no texto, o emprego de linguagem simples e a manutenção da consistência em toda a interface.

## 3. Acessibilidade na Web
- Web Content Accessibility Guidelines (WCAG) é o conjunto de recomendações voltado para tornar conteúdos web acessíveis para pessoas com deficiência.
- O objetivo central é permitir que qualquer indivíduo consiga interagir com serviços online, independentemente de suas habilidades cognitivas, sensoriais ou físicas.
- Acessibilidade e usabilidade devem ser integradas obrigatoriamente durante a construção de protótipos, sendo testadas antes do início da codificação do software.

### 3.1 Estrutura da WCAG
- Diretrizes: totalizam 13 itens que fornecem os objetivos básicos para orientar a criação de conteúdos acessíveis.
- Embora as diretrizes não sejam testáveis por si só, elas fornecem a estrutura necessária para a implementação dos critérios de sucesso.
- Critérios de sucesso: definem as regras que devem ser cumpridas e são categorizados em três níveis de conformidade.

### 3.2 Princípios de Acessibilidade
- Princípio perceptível: visa fornecer alternativas textuais para conteúdos não textuais e alternativas para mídias variadas.
- Garante que a informação e a estrutura sejam apresentadas de formas diferentes sem que ocorra perda de entendimento para o usuário.
- Práticas eficazes incluem o uso de ferramentas para tradução em Libras e a garantia de que imagens possuam descrições adequadas para leitores de tela.
- Em formulários, deve-se assegurar que os campos possuam rótulos claramente associados e mensagens de erro específicas para guiar a correção.

## 4. Engenharia de Usabilidade
- Usabilidade refere-se ao nível de esforço que um usuário deve empregar para utilizar efetivamente um produto de software.
- Atributos de uma interface de software:
  - Facilidade de aprendizado;
  - Velocidade de operação;
  - Robustez;
  - Facilidade de recuperação;
  - Adaptabilidade.

> [!TIP] DICAS: 
> - UI é o meio (a tela, o botão), enquanto UX é o resultado (o sentimento, a facilidade).

> [!CAUTION] OBSERVAÇÃO: 
> - Cai em prova: Acessibilidade e usabilidade não são conflitantes. Elas devem ser planejadas desde a fase de prototipação e design, e nunca deixadas apenas para o momento após a codificação.

# Verbo Haver

## 1. Definição
- Na maior parte das vezes, o verbo haver é usado com o sentido de existir, acontecer ou para indicar ideia de tempo. Quando usado com esses sentidos, ele é impessoal, por isso, quase sempre o verbo haver é conjugado na 3.ª pessoa do singular (ele/ela): há, havia, houve.
- Exemplos:
  - Não generalize! Há pessoas muito boas naquele bairro.
  - Havia muitos assaltos onde eu vivia.
  - Houve acidentes na estrada.
- Verbo impessoal é aquele que não têm sujeito e, por isso, não pode ser usado no plural, tal como os verbos haver, fazer, amanhecer, chover.
- Ao substituir o verbo haver, que é impessoal, pelos verbos existir, acontecer ou ocorrer, dos exemplos acima, eles são conjugados. Isso acontece, porque existir, acontecer e ocorrer são verbos pessoais.
- Exemplos:
  - Não generalize! Existem pessoas muito boas naquele bairro.
  - Aconteciam muitos assaltos onde eu vivia.
  - Ocorreram acidentes na estrada.

## 2. Concordância do Verbo Haver

### 2.1 Verbo haver no Singular
- Quando têm o sentido de existir, acontecer ou quando indica ideia de tempo (no sentido de fazer).
- É impessoal (não tem sujeito).
- Sempre fica na 3ª pessoa do singular.
- Não concorda com o complemento, mesmo que ele seja plural.
- Exemplos:
  - Há vídeos novos no canal!
  - Houve problemas na impressão dos exames.
  - Havia anos que não vinha me visitar.
- Quando o verbo haver tem o sentido de existir e está acompanhado por um verbo auxiliar, os dois verbos devem ficar no singular.
- Exemplos:
  - Deve haver uma saída.
  - Deve haver soluções para esse caso.
  - Pode haver alguma complicação.
  - Pode haver sérias complicações.

### 2.2 Verbo haver no Singular ou no Plural
- Quando é usado como verbo auxiliar. Nesses casos, somente o verbo auxiliar é conjugado, enquanto o verbo principal fica no particípio.
- Exemplos:
  - Havíamos provado todos os doces naquele dia. (verbo auxiliar: havíamos, verbo principal: provado);
  - Ela(s) havia(m) experimentado todas as roupas daquela loja! (verbo auxiliar: havia ou haviam, verbo principal: experimentado);
  - Haverão feito as contas de todos os gastos da festa? (verbo auxiliar: haverão, verbo principal: feito).

| HAVER NO SENTIDO DE EXISTIR (SINGULAR) | VERBO HAVER COMO AUXILIAR (SINGULAR OU PLURAL) |
|---|---|
| Havia pessoas cantando.	               | Eles(s) havia(m) escutado pessoas cantando.    |
| Havia vários tipos de patês.	         | Eles(s) havia(m) comido vários tipos de patês. |
| Havia emoção e alegria.	               | Eles(s) havia(m) sentido emoção e alegria.     |
| Havia belos penteados.	               | Eles(s) havia(m) visto belos penteados.        |
| Havia de tudo um pouco.	               | Eles(s) havia(m) reparado em tudo.             |


## 3. Conjugação do Verbo Haver

### 3.1 Formas Nominais do Verbo Haver

| INFINITIVO PESSOAL | INFINITIVO IMPESSOAL | GERÚNDIO | PARTICÍPIO |
|---|---|---|---|
| Haver eu          | Haver | Havendo | Havido |
| Haveres tu        |       |         |        |
| Haver ele/ela     |       |         |        |
| Havermos nós      |       |         |        |
| Haverdes vós      |       |         |        |
| Haverem eles/elas |       |         |        |

### 3.2 Conjugação do Verbo Haver no Modo Subjuntivo

| PRESENTE | PRETÉRITO IMPERFEITO | FUTURO |
|---|---|---|
| Que eu haja         | Se eu houvesse         | Quando eu houver          |
| Que tu hajas        | Se tu houvesses        | Quando tu houveres        |
| Que ele/ela haja    | Se ele/ela houvesse    | Quando ele/ela houver     |
| Que nós hajamos     | Se nós houvéssemos     | Quando nós houvermos      |
| Que vós hajais      | Se vós houvésseis      | Quando vós houverdes      |
| Que eles/elas hajam | Se eles/elas houvessem | Quando eles/elas houverem |

### 3.3 Conjugação do Verbo Haver no Modo Imperativo

| IMPERATIVO AFIRMATIVO | IMPERATIVO NEGATIVO |
|---|---|
| Há tu           | Não hajas tu        |
| Haja ele/ela    | Não haja ele/ela    |
| Hajamos nós     | Não hajamos nós     |
| Havei vós       | Não hajais vós      |
| Hajam eles/elas | Não hajam eles/elas |

> [!CAUTION] OBSERVAÇÃO:
> - Erros comuns (evitar):
>   - Errado: "Houveram muitos acidentes na estrada."
>   - Correto: "Houve muitos acidentes na estrada."
>   - Errado: "Haviam várias pessoas na fila."
>   - Correto: "Havia várias pessoas na fila."
>   - Exemplo: 
>     - Frase incorreta: "Sempre houveram problemas ambientais no Brasil."
>     - Frase correta: "Sempre houve problemas ambientais no Brasil."
>     - Por quê?
>     - "haver" significa "existir" → impessoal → singular.
> - Comparação com "existir":
>   - Há muitos problemas. (verbo no singular)
>   - Existem muitos problemas. (verbo no plural) 


> [!TIP] DICA: 
> - Macete para não errar:
>   - Pergunte: "O 'haver' aqui significa existir, ocorrer ou acontecer?"
>   - Se sim ⟶ 3ª pessoa do singular, sempre.
>   - Se não (verbo auxiliar) ⟶ pode flexionar.

> [!TIP] DICA: 
> - Substitua mentalmente por "existir":
> - Se puder trocar por "existem/existiam" ⟶ então "haver" fica no singular.
> - Exemplo:
>   - Mas havia/haviam muitos livros?
>   - Mas existiam muitos livros?
>   - Mas Haviam muitos livros? (errado) Mas Havia muitos livros? (correto)

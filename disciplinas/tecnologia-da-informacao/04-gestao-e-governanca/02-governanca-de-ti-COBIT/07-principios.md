# Princípios do COBIT 2019

## 1. Visão Geral dos Princípios
- O COBIT 2019 é fundamentado em um conjunto de nove princípios fundamentais, que servem para guiar a governança e a gestão da informação e tecnologia.
- Estes princípios são divididos em dois grupos principais: princípios para um sistema de governança e princípios para um framework de governança.

### 1.1 Divisão dos Grupos
- Sistema de governança: composto por 6 princípios;
- Framework de governança: composto por 3 princípios.

> [!CAUTION] OBSERVAÇÃO: 
> - É comum em provas de concurso a tentativa de inverter o quantitativo ou misturar os princípios dos dois grupos. Memorize que o sistema (a prática) possui mais princípios (6) que o framework (o modelo, com 3).

## 2. Princípios para um Sistema de Governança
- Estes princípios descrevem os requisitos essenciais para que um sistema de governança de TI organizacional seja eficaz e gere resultados.

### 2.1 Prover Valor para as Partes Interessadas
- O objetivo central é atender às necessidades dos stakeholders;
- O sistema deve gerar valor real a partir do uso da informação e tecnologia.

### 2.2 Abordagem Holística
- Um sistema de governança é composto por diversos tipos de componentes que trabalham de forma integrada;
- Inclui a interconexão entre processos, estruturas organizacionais, princípios, políticas, informação, cultura, ética, pessoas, habilidades e infraestrutura ⟶ visão do todo.

### 2.3 Sistema de Governança Dinâmico
- O sistema deve estar preparado para um ambiente mutável;
- Deve ser capaz de considerar os impactos da alteração de um ou mais fatores de desenho e se ajustar conforme necessário.

### 2.4 Diferenciar Governança de Gestão
- O sistema de governança deve possuir estruturas e atividades claras que não se confundem com as de gestão;
- Governança e gestão são disciplinas distintas com responsabilidades separadas dentro da organização.

### 2.5 Adaptado às Necessidades da Empresa
- O sistema deve ser desenhado com base em fatores de design que atendam às particularidades da organização;
- Utiliza parâmetros específicos para personalizar e priorizar os componentes da governança.

### 2.6 Sistema de Governança de Ponta a Ponta
- Não deve se limitar apenas à função de TI;
- Deve cobrir todo o processamento de informações e tecnologia em toda a organização, incluindo as áreas finalísticas.

> [!TIP] DICAS: 
> - Lembre-se que o princípio de ponta a ponta (fim a fim) significa que a governança de TI "sai do departamento de TI" e passa a olhar para o negócio como um todo.

## 3. Princípios para um Framework de Governança
- Estes princípios orientam a construção e a manutenção do modelo de referência utilizado para implementar o sistema de governança.

### 3.1 Baseado em um Modelo Conceitual
- O framework deve identificar os componentes principais e seus relacionamentos;
- O objetivo é maximizar a consistência e permitir a automação dos processos de governança.

### 3.2 Aberto e Flexível
- Deve permitir a adição de novos conteúdos e a abordagem de novos problemas de forma ágil;
- A flexibilidade deve ser mantida sem comprometer a integridade e a consistência do modelo.

### 3.3 Alinhado com Principais Padrões
- O framework deve estar em conformidade com os principais padrões, estruturas e regulamentos mundiais relacionados à governança.

### 3.4 Comparativo de Quantitativos
| GRUPO DE PRINCÍPIOS | QUANTIDADE DE ITENS |
|---|---|
| Sistema de governança | 6 |
| Framework de governança | 3 |

> [!CAUTION] OBSERVAÇÃO: 
> - Diferente de versões anteriores (como o COBIT 5), o COBIT 2019 adicionou formalmente os princípios específicos para o framework de governança.

# Cobit 2019 – Sistema de Governança e Componentes

## 1. Sistema de Governança
- O Cobit 2019 estabelece um sistema de governança composto por um conjunto de princípios, estruturas, processos e mecanismos que operam de forma sincronizada e ordenada.
- Esse sistema é responsável por garantir que a governança e a gestão da Tecnologia da Informação estejam devidamente alinhadas aos objetivos estratégicos da organização.
- O framework define como e por quem as decisões relacionadas à Ti são tomadas, além de estabelecer como tais decisões devem ser monitoradas e avaliadas.
- Diferente do PMBOK, que apresenta um sistema de entrega de valor, ou da ITIL v4, focada na cadeia de valor de serviço, o Cobit foca na estruturação dos componentes que sustentam o sistema de governança.
- O Cobit atua como um conjunto de diretrizes e não como um framework prescritivo; ele não determina decisões específicas de Ti ou arquiteturas tecnológicas.

## 2. Componentes do Sistema de Governança
- Componentes são fatores que, individual e coletivamente, permitem o funcionamento adequado do sistema de governança de uma organização.
- Estes elementos interagem entre si, resultando em uma abordagem holística para a governança da informação e tecnologia empresarial.
- O framework identifica sete componentes fundamentais que devem ser gerenciados para atingir os objetivos de governança.
- Os processos são os componentes mais conhecidos, mas não são os únicos necessários para um sistema eficaz.

### 2.1 Tabela de Descrição dos Componentes

| COMPONENTE | DEFINIÇÃO E ATUAÇÃO |
|---|---|
| Processos | Conjunto organizado de práticas e atividades para alcançar objetivos de ti. |
| Estruturas organizacionais | Entidades principais responsáveis pela tomada de decisão na organização. |
| Princípios, políticas e frameworks | Traduzem o comportamento desejado em orientações práticas para a gestão. |
| Informação | Dados produzidos e utilizados pela organização para o funcionamento da governança. |
| Cultura, ética e comportamento | Fatores individuais e coletivos essenciais para o sucesso das atividades. |
| Pessoas, habilidades e competências | Necessárias para a tomada de decisões e conclusão de atividades. |
| Serviços, infraestrutura e aplicativos | Tecnologia e sistemas que fornecem suporte ao processamento de ti. |

> [!CAUTION] OBSERVAÇÃO: 
> - No Cobit 5, esses elementos eram chamados de habilitadores; no Cobit 2019, o termo oficial passou a ser componentes.
> - O componente Cultura, Ética e Comportamento é frequentemente subestimado como fator de sucesso, mas é considerado vital pelo framework.

## 3. Princípios do Cobit 2019
- O framework organiza seus princípios em duas categorias distintas para facilitar a implementação da governança.
- Os princípios para um sistema de governança descrevem os requisitos fundamentais para o sistema funcionar na empresa.
- Os princípios para um framework de governança definem como o próprio modelo de referência deve ser construído.

### 3.1 Princípios para um Sistema de Governança
- Prover valor para as partes interessadas;
- Abordagem holística;
- Sistema de governança dinâmico;
- Governança distinta do gerenciamento;
- Adaptar-se às necessidades da empresa;
- Sistema de governança fim-a-fim.

### 3.2 Princípios para um Framework de Governança
- Baseado em um modelo conceitual;
- Aberto e flexível;
- Alinhado com os principais padrões globais.

> [!TIP] DICAS: 
> - Para provas discursivas: é importante memorizar os sete componentes, pois bancas como o ISS-SP já exigiram a listagem de pelo menos quatro deles.
> - Lembre-se: o Cobit não organiza processos de negócio ⟶ para essa finalidade, o guia adequado é o BPM CBok.

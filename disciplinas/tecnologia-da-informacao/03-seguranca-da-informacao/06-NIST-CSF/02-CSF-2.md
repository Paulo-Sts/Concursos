# Profiles

## 1. Conceito e Função dos CSF Profiles
- Os CSF Profiles são utilizados para descrever a postura de cibersegurança de uma organização.
- Consideram três elementos fundamentais:
  - Objetivos da organização;
  - Expectativas das partes interessadas (stakeholders);
  - Cenário de ameaças.
- A principal função é permitir a avaliação da postura atual e o planejamento da postura desejada.
- A criação de perfis ajuda a organização a alcançar os resultados desejados em termos de cibersegurança.

### 1.1 Importância para Avaliação e Planejamento
- Avalia a postura atual de cibersegurança.
- Planeja a postura desejada pela organização.
- Serve como ferramenta para gestão de riscos de cibersegurança.

## 2. Tipos de Perfis de Cibersegurança Organizacional

### 2.1 Perfil Atual
- Descreve os resultados que a organização está atingindo atualmente.
- Representa a situação real da segurança cibernética no momento da avaliação.
- Serve como base para identificar lacunas e pontos de melhoria.

### 2.2 Perfil Alvo
- Descreve os resultados desejados para atingir os objetivos de gestão de riscos de cibersegurança.
- Representa a situação ideal planejada pela organização.
- Orienta as ações e investimentos em segurança cibernética.

| TIPO DE PERFIL | DESCRIÇÃO | FINALIDADE |
|----------------|-----------|------------|
| Perfil atual | Resultados que a organização está atingindo atualmente | Avaliar a situação presente |
| Perfil alvo | Resultados desejados para atingir os objetivos de gestão de riscos | Planejar a situação futura desejada |

> [!TIP] DICAS:
> - A comparação entre o perfil atual e o perfil alvo é essencial para a análise de lacunas (gap analysis).
> - O perfil alvo deve estar alinhado com os objetivos estratégicos da organização e com sua apetite a risco.

## 3. Etapas para Criação e Uso de um CSF Profile

### 3.1 Definição do Escopo
- Primeiro passo para a criação do perfil organizacional.
- Determina qual será o escopo da avaliação.
- Deve ser documentado com base em fatos e suposições de alto nível.
- Pode abranger:
  - Toda a organização (escopo amplo);
  - Sistemas específicos (escopo restrito), como os sistemas financeiros.

### 3.2 Coleta de Informações Relevantes
- Segundo passo para a criação do perfil organizacional.
- Reúne dados necessários para preparar o perfil organizacional.
- Inclui informações sobre:
  - Políticas da organização;
  - Prioridades de gestão de risco;
  - Perfis de risco empresarial;
  - Análise de impacto de negócios (Business Impact Analysis – BIA);
  - Padrões de cibersegurança;
  - Recursos disponíveis na organização.

### 3.3 Criação do Perfil Organizacional
- Terceiro passo para a criação do perfil organizacional.
- Com as informações coletadas, elabora-se o perfil da organização.
- Determina-se o tipo de dados a serem incluídos.
- Considera-se as implicações de risco do perfil atual para planejar o perfil alvo.
- Pode-se usar um perfil comunitário como referência.

### 3.4 Análise de Lacunas e Elaboração do Plano de Ação
- Quarto passo para a criação do perfil organizacional.
- Consiste em identificar as diferenças entre o perfil atual e o perfil alvo.
- Permite identificar o que está faltando para alcançar o perfil desejado.
- A análise permite desenvolver um plano de ação priorizado.
- O plano inclui:
  - Registro de riscos;
  - Marcos necessários para resolver as diferenças.

### 3.5 Implementação do Plano de Ação e Atualização do Perfil
- Quinto passo no Cybersecurity Framework.
- Objetivo: mover a organização do perfil atual para o perfil alvo.
- Pode ter prazo determinado ou ser contínuo.
- Foco na melhoria contínua.
- Após a implementação, revisa-se e atualiza-se o perfil conforme necessário.

> [!CAUTION] OBSERVAÇÃO:
> - O ciclo de atividades descrito no Cybersecurity Framework pode ser repetido sempre que necessário para ajustar e aprimorar as práticas de segurança cibernética.
> - A implementação do plano de ação, com a possibilidade de ser um processo contínuo, é um ponto importante frequentemente cobrado em provas de concurso.
> - As etapas são fundamentais para criar um profile eficaz e são estruturadas em etapas cíclicas que se repetem constantemente.

### 3.6 Representação do Processo
- O modelo de cibersegurança é estruturado em etapas cíclicas.
- As etapas cíclicas se repetem constantemente.
- As etapas incluem: identificar, proteger, detectar, responder e recuperar.
- Essas etapas são fundamentais dentro da governança do Cybersecurity Framework.

> [!TIP] DICAS:
> - Memorize a sequência: escopo → coleta → criação → análise de lacunas → implementação.
> - A análise de lacunas é o ponto central que conecta o perfil atual ao perfil alvo.
> - A melhoria contínua é um princípio fundamental do CSF.

## 4. Usos dos CSF Profiles
- Os CSF Profiles podem ser usados para:
  - Documentar capacidades de cibersegurança atuais;
  - Comunicar com stakeholders externos;
  - Expressar requisitos de gerenciamento de riscos de cibersegurança.

### 4.1 Documentação de Capacidades Atuais
- Permite registrar formalmente as capacidades existentes.
- Serve como referência para auditorias e avaliações.
- Facilita o acompanhamento da evolução da segurança ao longo do tempo.

### 4.2 Comunicação com Stakeholders Externos
- Permite comunicar de forma clara e padronizada.
- Facilita o entendimento entre diferentes partes interessadas.
- Pode ser utilizado para demonstrar conformidade com requisitos.

### 4.3 Expressão de Requisitos de Gerenciamento de Riscos
- Auxilia na definição de requisitos claros para gestão de riscos.
- Permite traduzir objetivos de negócio em requisitos técnicos.
- Facilita a priorização de ações de segurança.

> [!TIP] DICAS:
> - O CSF Profile é uma ferramenta estratégica, não apenas técnica.
> - A comunicação com stakeholders externos é um uso importante para demonstrar maturidade em segurança.
> - O perfil expressa requisitos de gerenciamento de riscos, não apenas controles técnicos.

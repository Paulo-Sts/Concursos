# Conceitos de Internet e Intranet 4

## 1. Elementos de Interação e Conteúdo Digital
- Link ou hyperlink: elemento clicável que permite a conexão entre páginas da web ou arquivos, funcionando como uma ponte digital entre informações.
- Avatar: representação visual ou gráfica de um usuário em ambientes digitais como redes sociais, fóruns e jogos.
- Hashtag: palavra ou expressão precedida pelo símbolo cerquilha (#) utilizada para categorizar conteúdos e facilitar buscas por temas específicos.
- Influencer: indivíduo com capacidade de formar opiniões e influenciar decisões de compra ou comportamentos de seus seguidores.
- Streaming: tecnologia voltada para a reprodução de áudio, vídeo ou transmissões ao vivo em fluxo contínuo sem a necessidade de download integral do arquivo.

| CONCEITO | DESCRIÇÃO |
|---|---|
| Hyperlink | Navegação entre conteúdos por clique |
| Avatar | Representação estática ou animada |
| Hashtag | Ferramenta de categorização social |
| Streaming | Reprodução imediata sem download |

> [!TIP] DICAS: 
> - O streaming permite o acesso ao conteúdo enquanto os dados são transmitidos, economizando tempo e armazenamento local.

> [!CAUTION] OBSERVAÇÃO: 
> - O hyperlink não é exclusivo da internet; ele pode ser utilizado para navegação interna dentro de uma intranet.

## 2. Linguagem e Localização na Rede
- HTML (HyperText Markup Language): linguagem de marcação utilizada para estruturar e formatar conteúdos que serão interpretados por navegadores.
- URL (Uniform Resource Locator): endereço de rede padronizado que identifica a localização exata de um recurso, como uma página, imagem ou impressora.
- WWW (World Wide Web): sistema de documentos interconectados acessíveis via internet, cuja obrigatoriedade de uso no endereço das páginas não existe mais.

### 2.1 Linguagem HTML
- Classificação: não é considerada uma linguagem de programação, mas sim de marcação de hipertexto.
- Tags: utiliza marcações específicas para definir elementos, como o título da página exibido na aba do navegador.
- HTML5: versão mais recente que trouxe melhorias de desempenho e novas tags dinâmicas após seu lançamento em 2007.

### 2.2 Estrutura da URL
- Protocolo ou esquema: define o método de acesso ao recurso ⟶ exemplos incluem http, https, ftp e telnet.
- Host ou domínio: identifica o computador ou servidor na internet, podendo ser representado por um nome ou endereço ip.
- Porta: número técnico associado ao protocolo (ex.: porta 8080); geralmente é omitida por padronização e aparece logo após o host.
- Caminho: indica a hierarquia de diretórios e o nome do arquivo para localizar o objeto dentro do servidor.
- Parâmetros e fragmentos: informações adicionais para buscas dinâmicas ou referências a subseções de um documento.

| TERMINAÇÃO | SIGNIFICADO |
|---|---|
| .com | Finalidade comercial |
| .net | Recursos relacionados a redes |
| .gov | Portais governamentais |
| .org | Organizações e fundações |
| .br | Identificação do Brasil |

> [!TIP] DICAS: 
> - O código %20 em uma url é utilizado para representar um espaço em branco e manter a integridade do link.

> [!CAUTION] OBSERVAÇÃO: 
> - O protocolo http não é criptografado e não exige certificado ssl para o funcionamento do site, diferentemente do https.

## 3. Tecnologias e Infraestrutura
- WHOIS: banco de dados jurídico e técnico que lista todos os domínios registrados e sua disponibilidade.
- IoT (Internet das Coisas): conceito de rede que conecta dispositivos físicos à internet para troca de dados e automação.
- Sensores: dispositivos de baixo custo e potência fundamentais para a viabilidade da iot, permitindo capturar dados do ambiente.

### 3.1 Diferenças entre Internet e Intranet
- Abrangência: a internet é uma rede global e pública, enquanto a intranet é privada e restrita a uma organização.
- Tecnologia base: ambas utilizam o mesmo conjunto de protocolos tcp/ip para comunicação.
- Acesso: o acesso à intranet pode ser feito remotamente através de uma vpn, mas isso não a torna parte da rede pública.

| CRITÉRIO | INTERNET | INTRANET |
|---|---|---|
| Natureza | Pública | Privada |
| Acessibilidade | Geral | Restrita |
| Protocolos | Tcp/ip | Tcp/ip |

> [!CAUTION] OBSERVAÇÃO: 
> - Termos como www2 não indicam versões da web (como web 2.0 ou deep web), mas apenas nomes de servidores específicos de uma organização.

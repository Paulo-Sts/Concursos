# DOM 2

## 1. Manipulação de Conteúdo de Texto
- Existem três propriedades principais para manipular o conteúdo interno de uma tag HTML, cada uma com comportamento distinto para diferentes objetivos de acesso ao texto e elementos.

### 1.1 textContent
- Mostra todo o conteúdo de texto de um elemento, incluindo textos que foram ocultados por propriedades CSS, como `display: none`.
- Retorna o conteúdo textual completo, sem formatação, ignorando estilos e tags.
- Exemplo de uso: `console.log(elemento.textContent);`

### 1.2 innerHTML
- Mostra todo o conteúdo do texto e também o HTML interno do elemento.
- Retorna absolutamente tudo, incluindo as tags HTML e seus atributos.
- Útil para manipular a estrutura interna do elemento, podendo inserir novo HTML.
- Exemplo de uso: `console.log(elemento.innerHTML);`

### 1.3 innerText
- Mostra apenas o texto que está visível na página, respeitando as regras de estilo aplicadas (ex.: elementos com `display: none` não são exibidos).
- Retorna somente o conteúdo textual que o usuário consegue ver na interface.
- Exemplo de uso: `console.log(elemento.innerText);`

> [!TIP] DICAS:
> - Use `textContent` quando precisar de todo o texto, mesmo o oculto; use `innerText` quando quiser apenas o texto visível; use `innerHTML` para acessar ou modificar a estrutura HTML.
> - O `innerHTML` é o mais utilizado em provas, pois permite manipular tanto texto quanto tags.

### Exemplo de Código
```javascript
<div id="example">
  <p>Primeiro parágrafo<span style="display: none"> não visível</span>.</p>
</div>
<script>
  var elem = document.getElementById("example");
  console.log(elem.textContent); // Mostra todo o texto: "Primeiro parágrafo não visível"
  console.log(elem.innerHTML);   // Mostra todo o HTML interno: "<p>Primeiro parágrafo<span style="display: none"> não visível</span>.</p>"
  console.log(elem.innerText);   // Mostra apenas o texto visível: "Primeiro parágrafo"
</script>
```

### Tabela Comparativa
| PROPRIEDADE | O QUE RETORNA |
|-------------|---------------|
| textContent | Todo o conteúdo de texto, incluso o oculto por CSS |
| innerHTML   | Todo o conteúdo de texto e as tags HTML internas |
| innerText   | Apenas o texto que está visível na página |

## 2. Manipulação de Eventos
- Eventos são ações ou ocorrências detectadas pelo navegador, geralmente resultantes de interação do usuário com a página.
- A linguagem JavaScript permite configurar funções para responder a esses eventos, tornando a página interativa.

### 2.1 addEventListener
- Configura uma função que será chamada sempre que o evento especificado for enviado ao elemento.
- Método que permite anexar um ouvinte de eventos a qualquer elemento DOM.
- Sintaxe: `elemento.addEventListener(evento, função);`

> [!CAUTION] OBSERVAÇÃO:
> - O `addEventListener` é a forma mais recomendada e moderna de lidar com eventos em JavaScript, pois permite adicionar múltiplos ouvintes para o mesmo evento em um elemento.

### 2.2 Tipos Comuns de Eventos
- `click`: ocorre quando o usuário clica em um elemento (combina as ações de mousedown e mouseup).
- `mousedown`: ocorre quando o botão do mouse é pressionado sobre um elemento.
- `mouseup`: ocorre quando o botão do mouse é solto sobre um elemento.
- `keydown`: ocorre quando uma tecla é pressionada.
- `load`: ocorre quando a página ou recurso é completamente carregado.

### Exemplo de Código
```javascript
var button = document.getElementById("meuBotao");
button.addEventListener("click", function() {
  alert("Botão clicado!");
});
```

> [!TIP] DICAS:
> - O evento `click` é o mais comum e cobrado em provas; é uma combinação de `mousedown` e `mouseup`.
> - Lembre-se de que o `addEventListener` é um método que deve ser chamado a partir de um elemento selecionado.

### 2.3 Seleção de Elementos para Eventos
- Para adicionar um evento, primeiro é necessário selecionar o elemento desejado no DOM.
- Métodos comuns de seleção:
  - `document.getElementById("id")`: seleciona um elemento pelo seu ID (único).
  - `document.querySelector("#id")`: seleciona o primeiro elemento que corresponde ao seletor CSS.
  - `document.getElementsByClassName("classe")`: seleciona todos os elementos com determinada classe.

### Exemplo de Seleção e Evento
```javascript
// Forma correta e mais comum para questões de concurso
document.getElementById("myButton").addEventListener("click", function() {
  // código a ser executado
});
```

> [!CAUTION] OBSERVAÇÃO:
> - O JavaScript puro (vanilla JS) não utiliza cifrão (`$`) ou funções como `click()` diretamente sem seleção prévia; essas são características de bibliotecas como jQuery.
> - A sintaxe `document["msgOut"].innerHTML` está incorreta; o correto é `document.getElementById` ou `document.querySelector`.

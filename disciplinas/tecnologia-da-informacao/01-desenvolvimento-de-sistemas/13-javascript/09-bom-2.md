# BOM 2

## 1. Browser Object Model (Bom)
- O BOM é um conjunto de objetos que fornecem acesso ao navegador e à janela do navegador.
- O objeto `window` é o elemento raiz do BOM, sendo o objeto global do JavaScript no navegador.
- Todos os outros objetos do BOM são derivados do objeto `window`.

### 1.1 Objetos do BOM
- `window`: objeto global e raiz do BOM.
- `location`: fornece informações sobre o URL da página carregada.
- `history`: permite acessar e manipular o histórico de navegação.
- `document`: representa o conteúdo HTML da página.
- `navigator`: fornece informações sobre o navegador.
- `screen`: fornece informações sobre a tela do dispositivo.

> [!TIP] DICAS:
> - O `window` é o objeto raiz, portanto, os demais objetos podem ser acessados como `window.location`, `window.history`, etc.
> - Em muitos casos, é possível omitir o `window` e acessar diretamente `location`, `history`, `document`, etc.

## 2. Location
- O objeto `location` fornece informações sobre o URL da página carregada na janela do navegador.
- Permite manipular o histórico de navegação e redirecionar o navegador para outro URL.
- Refere-se à localização da página (URL do site), não à localização geográfica do usuário.

### 2.1 Funções principais do Location
- Acessar informações sobre o URL atual da página (protocolo, host, pathname, etc.).
- Redirecionar o navegador para outro URL.
- Recarregar a página atual.

### 2.2 Propriedades do Location
- As propriedades do `location` correspondem às partes que compõem uma URL.

#### 2.2.1 href
- Retorna ou define a URL completa da página.
- É o endereço inteiro da URL.

#### 2.2.2 protocol
- Indica o protocolo da URL (ex.: `http:` ou `https:`).
- Método usado para acessar ou enviar dados de uma rede.

#### 2.2.3 host
- Combina o hostname e a porta (se houver) em uma string.
- hostname é o nome do domínio (ex.: `example`, `google`, `youtube`).

#### 2.2.4 porta
- Identificação no servidor da rede.
- Exemplo: porta `80` para tráfego HTTP.
- Exemplo de URL: `https://www.example.com:8080/products/list`
  - protocol: `https:`
  - host: `www.example.com:8080`
  - porta: `8080`
  - pathname: `/products/list`

#### 2.2.5 pathname
- Retorna o caminho após o hostname.
- Caminho para o recurso do servidor que será acessado.

> [!CAUTION] OBSERVAÇÃO:
> - O `location.href` retorna a URL completa da página atual. Para acessar apenas o protocolo, utiliza-se `location.protocol`.
> - A propriedade `host` combina hostname e porta. Se a porta não estiver presente, apenas o hostname é retornado.

## 3. History
- O objeto `history` permite acessar o histórico de navegação do usuário.
- Permite navegar para páginas anteriores ou seguintes à página atual.

### 3.1 Funções principais do History
- Navegar para páginas anteriores ou seguintes no histórico de navegação.
- Acessar o número total de páginas no histórico.

> [!TIP] DICAS:
> - Métodos comuns: `history.back()` (voltar), `history.forward()` (avançar) e `history.go(n)` (navegar para uma página relativa).

## 4. Document
- O objeto `document` representa o conteúdo HTML de uma página web carregada em uma janela do navegador.
- É a porta de entrada para o DOM (Document Object Model).

### 4.1 Funções principais do Document
- Acessar e manipular elementos HTML na página.
- Adicionar, remover e modificar elementos HTML, atributos e estilos.
- Manipular eventos do DOM.
- Acessar informações sobre o documento, como URL e título.

> [!CAUTION] OBSERVAÇÃO:
> - O `document` é um objeto do BOM, mas está intimamente ligado ao DOM. Os métodos de manipulação de elementos pertencem ao DOM, mas o objeto `document` é acessado via BOM.

## 5. Navigator
- O objeto `navigator` fornece informações sobre o navegador.

### 5.1 Funções principais do Navigator
- Acessar informações sobre o navegador (nome, versão, fabricante, etc.).
- Determinar recursos disponíveis (suporte a cookies, JavaScript, geolocalização, etc.).
- Detectar o idioma preferido do usuário.

> [!TIP] DICAS:
> - Exemplos de propriedades: `navigator.userAgent` (identificação do navegador), `navigator.language` (idioma), `navigator.cookieEnabled` (verifica se cookies estão habilitados).

## 6. Screen
- O objeto `screen` fornece informações sobre a tela do dispositivo.

### 6.1 Funções principais do Screen
- Acessar informações sobre a tela (largura, altura, resolução, etc.).
- Determinar a orientação da tela.

> [!TIP] DICAS:
> - Exemplos de propriedades: `screen.width` e `screen.height` (dimensões da tela), `screen.availWidth` e `screen.availHeight` (dimensões disponíveis, excluindo barras de tarefas).

## 7. Métodos de Interação com o Usuário
- São métodos fornecidos pelo BOM para interação com o usuário.
- Quando um desses métodos é chamado, a interação com a página fica bloqueada até que o usuário responda à caixa de diálogo.
- O script fica bloqueado até que o usuário interaja com a caixa de diálogo.

### 7.1 alert()
- Exibe uma caixa de diálogo com uma mensagem e um botão "OK".
- Usado para informar o usuário sobre algo que requer sua atenção.
- O usuário não tem como interagir, responder ou cancelar, apenas pressionar "OK".
- Exemplo:
```javascript
alert("Olá!");
```

> [!TIP] DICAS:
> - O `alert` é utilizado para exibir mensagens informativas. O usuário deve clicar em "OK" para continuar.

### 7.2 confirm()
- Exibe uma caixa de diálogo com uma mensagem e os botões "OK" e "Cancelar".
- Usado para confirmar ações do usuário.
- Exemplo:
```javascript
confirm("Você realmente quer se deslogar da sua conta?");
```
- O método retorna `true` se o usuário clicar em "OK" e `false` se clicar em "Cancelar".

> [!TIP] DICAS:
> - O `confirm` é útil para ações destrutivas ou que exigem confirmação do usuário.

### 7.3 prompt()
- Exibe uma caixa de diálogo que solicita ao usuário que insira algum texto.
- O primeiro parâmetro é a instrução (ex.: "Digite seu nome").
- O segundo parâmetro é o valor padrão ou orientação sobre onde o usuário deve inserir as informações.
- Exemplo:
```javascript
prompt("Digite seu nome", "Seu nome aqui");
```
- O método retorna o texto inserido pelo usuário ou `null` se o usuário clicar em "Cancelar".

### Tabela Comparativa dos Métodos de Interação
| MÉTODO | DESCRIÇÃO | BOTÕES | RETORNO |
|--------|-----------|--------|---------|
| alert  | Exibe uma mensagem informativa | OK | Void (não retorna valor) |
| confirm | Exibe uma mensagem de confirmação | OK e Cancelar | Booleano (true/false) |
| prompt | Exibe uma mensagem solicitando entrada de texto | OK e Cancelar | String ou null |

> [!CAUTION] OBSERVAÇÃO:
> - Os métodos `alert`, `confirm` e `prompt` são nativos do JavaScript e não requerem bibliotecas adicionais.
> - São métodos do objeto `window`, podendo ser chamados como `window.alert()`, `window.confirm()` e `window.prompt()`.
> - O método `prompt` não utiliza redirecionadores (`>>`, `<<`). A sintaxe correta é `prompt("mensagem", "valor padrão")`.
> - Diferentemente do `alert` e `confirm`, o `prompt` permite a entrada de dados pelo usuário.

# VUE 2

## 1. Funções Globais
- Conjunto de métodos disponíveis globalmente no Vue que permitem manipular reatividade, registrar componentes e controlar o ciclo de atualização do DOM.
- Utilizadas para operações que não dependem de uma instância específica do Vue, como adicionar propriedades reativas ou registrar diretivas personalizadas.

### 1.1 Tabela de Funções Globais

| FUNÇÃO | DESCRIÇÃO | USO COMUM |
|--------|-----------|-----------|
| Vue.set | Adiciona uma propriedade reativamente a um objeto ou item a um array | Utilizado para garantir reatividade quando propriedades são adicionadas após a criação do objeto |
| Vue.delete | Remove uma propriedade de um objeto ou um item de um array reativamente | Usado para remover propriedades reativas, garantindo que as dependências sejam atualizadas |
| Vue.nextTick | Executa código após o próximo DOM update, permitindo acesso ao DOM atualizado | Frequente em testes ou quando mudanças precisam ser refletidas no DOM para operações subsequentes |
| Vue.observable | Torna um objeto reativo para ser usado como estado local fora de uma instância Vue | Usado para criar um estado reativo acessível globalmente sem a necessidade de uma instância Vue completa |
| Vue.mixin | Permite definir opções de componente que podem ser reutilizadas em vários componentes | Empregado para compartilhar funcionalidades comuns entre vários componentes, como métodos ou hooks de ciclo de vida |
| Vue.extend | Cria um sub-construtor que herda as opções de uma instância Vue ou componente | Usado para criar classes de componentes base que podem ser estendidas, facilitando a reutilização e a organização do código |
| Vue.component | Registra ou recupera um componente global | Utilizado para definir componentes que podem ser reutilizados em várias partes de uma aplicação |
| Vue.directive | Registra ou recupera uma diretiva personalizada | Aplicado para criar diretivas customizadas que adicionam funcionalidades interativas ou manipulações específicas do DOM |

> [!TIP] DICAS:
> - Vue.set e Vue.delete são essenciais para manter a reatividade quando se manipulam objetos e arrays fora do escopo inicial de dados.
> - Vue.nextTick é frequentemente cobrado em provas que envolvem manipulação do DOM após alterações de estado.

## 2. Diretivas
- As diretivas são instruções usadas nos templates (HTML) para manipular o DOM de forma reativa.
- Possuem o prefixo "v-" para indicar que são recursos do Vue e diferenciá-las de atributos HTML regulares.
- Adicionam comportamento reativo aos elementos do DOM, permitindo:
  - Manipulação condicional de elementos (exibir algo se uma condição for verdadeira ou falsa);
  - Execução de loops;
  - Tratamento de eventos (interações do usuário).

### 2.1 Diretivas Comuns
- v-bind: usada para vincular um ou mais atributos, ou uma propriedade de componente, a uma expressão.
- v-model: cria uma ligação bidirecional em elementos de formulário.
- v-for: renderiza uma lista de elementos com base nos dados de um array.
- v-if, v-else-if, v-else: controla condicionalmente a renderização de blocos.
- v-on: escuta eventos DOM.
- v-show: alterna a propriedade display de um elemento baseando-se na verdade do valor de uma expressão.
- v-text: atualiza o textContent do elemento.
- v-html: atualiza o innerHTML do elemento.

> [!CAUTION] OBSERVAÇÃO:
> - v-show e v-if controlam a visibilidade, mas com diferenças cruciais:
>   - v-show altera apenas a propriedade display do elemento (o elemento permanece no DOM);
>   - v-if adiciona ou remove o elemento do DOM (mais custoso em termos de performance).
> - Essas diferenças são frequentemente exploradas em questões de concurso.

### 2.2 Exemplo Prático de Diretivas
- No template, um input utiliza v-model, ligando o modelo de dados à visualização do usuário.
- Um placeholder exibe uma mensagem indicativa ao usuário.
- Quando o usuário insere dados, estes são atualizados instantaneamente no modelo de dados.
- Um parágrafo recebe o texto da variável "message" via v-text.
- Um botão escuta um evento de clique (v-on) chamando o método "reverseMessage".
- Dependendo do tamanho da mensagem, é exibida uma indicação se a mensagem é longa ou curta.
- Uma lista é iterada por v-for dentro de um elemento li, percorrendo itens como frutas, cores, roupas, etc.
- Cada elemento do array de itens é renderizado na tela; o índice do array é usado como valor da key para identificar cada item de forma única.
- V-html exibe o HTML bruto definido.

> [!TIP] DICAS:
> - O uso de key em v-for é obrigatório para otimizar a renderização de listas e evitar problemas de reatividade.
> - O índice do array pode ser acessado como segundo parâmetro no v-for.

### 2.3 Exemplo de Código (Estrutura Básica)
- No script, os dados são exportados:
  - data retorna um objeto contendo a mensagem (inicia vazia) utilizada no v-model e no v-text.
  - array de itens contendo objetos com propriedades e valores de texto (ex: "aprender Vue", "construir algo incrível").
  - raw HTML define a tag HTML que será renderizada com estilização e HTML dinâmico.
- O método "reverseMessage" (chamado pelo botão) reverte a mensagem definida no escopo:
  - Pega a mensagem, divide-a em um array de caracteres com split(''), reverte a ordem com reverse(), e junta novamente com join('').
  - Exemplo: "Olá" se transforma em "Alô".

## 3. Hooks do Ciclo de Vida
- Os hooks são utilizados para criar, utilizar e destruir componentes.
- Existem hooks específicos para cada etapa do ciclo de vida de um componente.

### 3.1 Tabela de Hooks do Ciclo de Vida

| HOOK | DESCRIÇÃO | USO COMUM |
|------|-----------|-----------|
| beforeCreate | Chamado imediatamente após a instância ser inicializada | Usado para configuração de plugins ou configurações iniciais que não dependem de reatividade |
| created | Chamado após a instância ser criada, onde os dados e eventos estão configurados | Ideal para fetch de dados e outras lógicas de inicialização que não envolvem manipulação do DOM |
| beforeMount | Chamado antes do componente ser montado no DOM | Usado para lógicas finais antes da montagem do DOM; raramente necessita manipulação direta do DOM, pois este ainda não está renderizado |
| mounted | Chamado após o componente ser montado no DOM | Comumente usado para manipulações do DOM, integrações com plugins que requerem que o elemento esteja presente, ou para iniciar animações |
| beforeUpdate | Chamado antes da re-renderização do componente devido a mudanças de dados | Usado para acessar o estado atual do DOM antes de ele ser atualizado, geralmente para obter tamanhos ou estados que serão alterados pela atualização |
| updated | Chamado após qualquer re-renderização do componente | Ideal para operações que dependem de mudanças do DOM já terem sido aplicadas, como ajustes pós atualização |
| beforeDestroy | Chamado imediatamente antes de um componente ser destruído | Usado para limpeza: desvincular event handlers, cancelar assinaturas ou invalidar timers |
| destroyed | Chamado após um componente ter sido destruído | Usado para executar limpeza final após o componente ser completamente desmontado, como remover o componente de um gerenciador de estado global |

> [!CAUTION] OBSERVAÇÃO:
> - A ordem de execução dos hooks é fixa e deve ser memorizada: beforeCreate → created → beforeMount → mounted → beforeUpdate → updated → beforeDestroy → destroyed.
> - Questões de concurso frequentemente perguntam qual hook é mais adequado para cada tipo de operação (ex: fetch de dados em created, manipulação de DOM em mounted).

## 4. Hooks de Composição
- Antes do Vue Composition API, a configuração era feita exclusivamente por meio da Options API (data e methods definidos de forma declarativa, com cada configuração separada).
- Com a Composition API, a abordagem tornou-se mais flexível e modular, organizando a lógica por funcionalidades em vez de por opções de configuração.
- Os hooks de composição são usados dentro da função setup.

### 4.1 Setup
- No ciclo de vida do Vue, o setup é criado logo após a instância, mas é executado antes dos hooks created e beforeCreated.
- A função setup é o ponto de entrada para o uso da Composition API.

### 4.2 Ref
- Usado para criar uma referência reativa a um valor primitivo.
- Qualquer mudança neste valor força os componentes que o utilizam a se atualizarem.
- Exemplo: uma constante é definida com um ref, inicialmente atribuída a um valor primitivo (ex: número zero).
- O valor retornado pode ser alterado de forma reativa e dinâmica.

### 4.3 Reactive
- Semelhante a ref, mas usado para criar objetos ou arrays reativos.
- Destinado a tornar objetos normais reativos.

### 4.4 Computed
- Cria uma propriedade computada que reage automaticamente a mudanças nas suas dependências.
- Útil para derivar outros valores a partir de estados reativos.
- Exemplo: calcular o dobro de um valor de contador.
- O hook computed é usado para criar propriedades computadas que são reativas e otimizadas para cálculos que dependem de outros dados reativos, sem causar efeitos colaterais.

### 4.5 Watch
- Permite observar reações a mudanças em uma ou mais fontes de dados reativas e executar uma função de callback quando essas mudanças ocorrem.
- Monitora a fonte de dados e aciona a função assim que uma alteração é detectada.
- Exemplo de uso:
  ```javascript
  import { watch } from 'vue';
  setup() {
    const count = ref(0);
    watch(count, (newValue, oldValue) => {
      console.log(`count changed from ${oldValue} to ${newValue}`);
    });
    return { count };
  }
  ```

### 4.6 onMounted, onUpdated, onUnmounted
- Equivalentes funcionais dos hooks de ciclo de vida tradicionais, mas usados dentro da setup function na Composition API.
- onMounted: executado logo após o componente ser adicionado ao DOM, sendo ideal para operações que dependem da presença de elementos DOM.
- onUpdated: executado toda vez que o componente é atualizado.
- onUnmounted: executado antes do componente ser desmontado.

### 4.7 Exemplo Prático de Hooks de Composição

```vue
<template>
  <div>
    <h1>{{ count }}</h1>
    <button @click="increment">Increment</button>
  </div>
</template>

<style>
  button {
    margin-top: 20px;
    padding: 10px 20px;
    font-size: 16px;
    cursor: pointer;
  }
</style>

<script>
  import { ref, onMounted, onUpdated, onUnmounted } from 'vue';

  export default {
    setup() {
      const count = ref(0);
      const increment = () => {
        count.value++;
      };

      onMounted(() => {
        console.log('Componente foi montado!');
      });

      onUpdated(() => {
        console.log('Componente foi atualizado!');
      });

      onUnmounted(() => {
        console.log('Componente será desmontado!');
      });

      return { count, increment };
    }
  }
</script>
```

> [!CAUTION] OBSERVAÇÃO:
> - Ref e Reactive são frequentemente confundidos em provas. Ref é para valores primitivos; Reactive é para objetos e arrays.
> - watch requer especificação explícita da fonte de dados, diferentemente de watchEffect que executa imediatamente e reage automaticamente a qualquer mudança nas suas dependências reativas, sem necessidade de especificação explícita.
> - onMounted é o hook correto para operações que dependem da presença do elemento no DOM, como manipulações diretas ou integração com bibliotecas de terceiros.

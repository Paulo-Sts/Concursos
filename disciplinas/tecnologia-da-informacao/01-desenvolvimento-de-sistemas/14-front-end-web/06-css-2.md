# CSS3 - Elementos Inline e Block, Cores e Modelo Caixa

## 1. Elementos Inline e Block
- Os elementos HTML são classificados em duas categorias principais quanto ao seu comportamento de exibição: inline e block.

### 1.1 Elementos Inline
- Não iniciam uma nova linha e ocupam apenas a largura do seu conteúdo.
- Exemplos: span, a, strong, em.
- Comportamento: se houver espaço disponível na mesma linha, o próximo elemento inline é posicionado ao lado do anterior.
- Exemplo de estilização:
```html
<style>
.inline-example {
  border: 1px solid blue;
  color: blue;
}
</style>
<span class="inline-example">Texto</span>
<a class="inline-example" href="#">Link</a>
```
- Explicação: cada tag contém um texto que terá a cor e a borda azul ao redor, ocupando apenas o espaço necessário para o texto contido.

### 1.2 Elementos Block
- Começam em uma nova linha e ocupam toda a largura disponível do contêiner.
- Exemplos: div, p, h1.
- Comportamento: se estendem do início ao fim da largura disponível, mesmo que haja espaço não utilizado ao redor.

> [!CAUTION] OBSERVAÇÃO:
> - A diferença fundamental entre inline e block está no fluxo do documento: elementos inline fluem no texto, enquanto elementos block criam quebras de linha e ocupam toda a largura disponível.

## 2. Cores em CSS3
- As cores podem ser especificadas de várias maneiras: nomes de cores, valores hexadecimais, valores RGB, valores RGBA, valores HSL e valores HSLA.

### 2.1 Nomes de Cores
- Usam palavras-chave em inglês que são nomes reservados do CSS.
- Exemplo:
```css
body {
  background-color: lightblue;
  color: darkred;
}
```

### 2.2 Valores Hexadecimais
- Consistem em um símbolo # seguido de 3 ou 6 dígitos (0 a 9 e A a F).
- Estrutura: #RRGGBB, onde:
  - Os dois primeiros dígitos correspondem ao vermelho;
  - Os dois seguintes ao verde;
  - Os dois últimos ao azul.
- Exemplos:
  - #000000 - Preto;
  - #FFFFFF - Branco;
  - #FF0000 - Vermelho puro;
  - #00FF00 - Verde puro;
  - #0000FF - Azul puro.
- É possível simplificar para três dígitos, onde cada dígito é duplicado (ex: #F00 equivale a #FF0000).
- Exemplo de aplicação:
```css
h1 {
  color: #ff4500; /* Laranja */
}
```
- Explicação: #FF4500 possui FF (máximo de vermelho), 45 (quantidade intermediária de verde) e 00 (ausência de azul).

### 2.3 Valores RGB e RGBA
- RGB: cada cor (red, green, blue) tem um valor de 0 a 255.
- Sintaxe: `rgb(red, green, blue)`.
- RGBA: adiciona o canal alfa para transparência, com valores de 0 (totalmente transparente) a 1 (totalmente opaco).
- Sintaxe: `rgba(red, green, blue, alpha)`.
- Exemplo de container com borda laranja com 60% de opacidade:
```css
.container {
  border-color: rgba(255, 128, 0, 0.6);
}
```
- Explicação: 255 é o valor máximo de vermelho, 128 é aproximadamente metade do valor de verde, 0 indica ausência de azul e 0.6 representa 60% de opacidade.

- Exemplo de fundo roxo com 40% de opacidade:
```css
.container {
  background-color: rgba(75, 0, 128, 0.4);
}
```
- Explicação: 75 é um valor baixo de vermelho, 0 indica ausência de verde, 128 é aproximadamente metade do valor de azul e 0.4 representa 40% de opacidade.

- Exemplo de texto rosa com 80% de opacidade:
```css
.container {
  color: rgba(255, 50, 128, 0.8);
}
```
- Explicação: 255 é o valor máximo de vermelho, 50 é um valor baixo de verde, 128 é aproximadamente metade do valor de azul e 0.8 representa 80% de opacidade.

### 2.4 Gradientes Lineares (linear-gradient)
- Criam uma transição de cor ao longo de uma linha reta.
- Sintaxe: `linear-gradient(direção, cor1, cor2, ...)`.
- Exemplo básico (de cima para baixo):
```css
.gradient {
  width: 300px;
  height: 200px;
  background: linear-gradient(to bottom, red, blue);
}
```
- Explicação: a primeira cor é posicionada na parte superior e transiciona suavemente até a segunda cor na parte inferior.
- Exemplo com múltiplas cores e ângulo:
```css
.gradient {
  width: 300px;
  height: 200px;
  background: linear-gradient(60deg, red, orange 30%, yellow 50%, green 70%);
}
```
- Explicação: o gradiente é inclinado em 60 graus; a primeira cor é vermelha, seguida por laranja (aproximadamente 30% da área), na metade ocorre a transição para amarelo e a partir de 70% a cor transita para verde.

> [!TIP] DICAS:
> - A direção pode ser definida por palavras-chave (to top, to bottom, to left, to right) ou por ângulos em graus.
> - As porcentagens definem os pontos exatos onde ocorrem as transições de cor.

### 2.5 Gradientes Radiais (radial-gradient)
- Demonstram uma transição de cor a partir de um ponto central, formando um padrão circular.
- Sintaxe: `radial-gradient(posição, cor1, cor2, ...)`.
- Exemplo básico:
```css
.radial {
  background: radial-gradient(red, blue);
}
```
- Explicação: o gradiente começa com vermelho no centro e transiciona para azul nas bordas.

- Exemplo com posição e forma personalizadas:
```css
.radial {
  background: radial-gradient(circle at 20% 30%, red, blue);
}
```
- Explicação: a forma é definida como círculo e o centro do gradiente é deslocado para 20% horizontal e 30% vertical.

### 2.6 Valores HSL e HSLA
- HSL: Hue (matiz), Saturation (saturação) e Lightness (luminosidade).
- Sintaxe: `hsl(hue, saturation%, lightness%)`.
- HSLA: adiciona o canal alfa para transparência.
- Sintaxe: `hsla(hue, saturation%, lightness%, alpha)`.
- Matiz (hue): especificada em graus de 0 a 360:
  - 0 ou 360 = vermelho;
  - 120 = verde;
  - 240 = azul.
- Saturação e luminosidade: variam de 0% a 100%.
- Alfa: varia de 0 a 1.
- Exemplos:
```css
/* Azul parcialmente transparente sobre fundo vermelho */
border-color: hsla(240, 100%, 50%, 0.3);
/* Fundo vermelho semitransparente */
background-color: hsla(0, 100%, 50%, 0.5);
/* Verde semitransparente */
color: hsla(120, 100%, 50%, 0.75);
```
- Explicação: no primeiro exemplo, a cor é definida como 240 graus (azul), com 100% de saturação e 50% de luminosidade, com 30% de transparência. No segundo, 0 graus (vermelho) com 50% de transparência. No terceiro, 120 graus (verde) com 75% de transparência.

> [!CAUTION] OBSERVAÇÃO:
> - No CSS, "red" é um valor do tipo palavra-chave, enquanto "#f00" é um valor do tipo notação hexadecimal, não funcional.

## 3. Modelo Caixa (Box Model)
- O modelo de caixa descreve como os elementos HTML são renderizados no navegador, considerando a largura, altura, margens, bordas e preenchimento de cada elemento, tratando-os como caixas.

### 3.1 Componentes do Modelo Caixa
- Conteúdo (content): área onde estão os textos, imagens ou outros conteúdos; é o que o usuário vê.
- Preenchimento (padding): espaço entre o conteúdo e a borda.
- Borda (border): envolve o preenchimento e o conteúdo; se não houver preenchimento, envolve diretamente o conteúdo.
- Margem (margin): espaço externo que separa a borda do elemento de outros elementos.

### 3.2 Cálculo das Dimensões
- Largura Total = Largura do Conteúdo + Preenchimento (esquerdo + direito) + Borda (esquerda + direita) + Margem (esquerda + direita)
- Exemplo:
  - Largura do conteúdo: 300px;
  - Preenchimento: 50px de cada lado (total: 100px);
  - Borda: 5px de cada lado (total: 10px);
  - Margem: 100px.
- Cálculo: 300px + 100px + 10px + 100px = 510px (largura total considerando a margem).
- Sem considerar a margem: 300px + 100px + 10px = 410px.

### 3.3 Propriedades do Modelo Caixa
| PROPRIEDADE | DESCRIÇÃO |
|-------------|-----------|
| Width | Define a largura da área de conteúdo. |
| Height | Define a altura da área de conteúdo. |
| Padding | Define o espaço interno entre o conteúdo e a borda. |
| Border | Define a espessura, estilo e cor da borda ao redor do elemento. |
| Margin | Define o espaço externo entre a borda do elemento e outros elementos. |

### 3.4 Shorthand para Margin e Padding
- A sintaxe abreviada segue a ordem horária: topo, direita, inferior, esquerda.
- Regras para valores omitidos:
  - Um valor: aplica-se a todos os lados;
  - Dois valores: o primeiro aplica-se ao topo e inferior; o segundo à direita e esquerda;
  - Três valores: o primeiro aplica-se ao topo; o segundo à direita e esquerda; o terceiro à inferior;
  - Quatro valores: aplicam-se respectivamente a topo, direita, inferior e esquerda.
- Exemplo com três valores:
```css
margin: 25px 50px 75px;
```
- Explicação:
  - Topo: 25px;
  - Direita: 50px;
  - Inferior: 75px;
  - Esquerda: como o valor foi omitido, assume o valor do lado oposto (direita), portanto 50px.

> [!CAUTION] OBSERVAÇÃO:
> - A propriedade margin define o espaço externo entre elementos, enquanto o padding define o espaço interno entre o conteúdo e a borda.
> - A margin não está relacionada ao conteúdo interno do elemento, mas sim à distância entre esse elemento e outros elementos na página.

## 4. Box-Sizing
- Propriedade que modifica o modelo de caixa padrão usado para calcular altura e largura.

### 4.1 Valores da Propriedade Box-Sizing
- content-box (padrão): altura e largura referem-se apenas ao conteúdo visível. O preenchimento e a borda são adicionados ao tamanho definido.
- border-box: altura e largura incluem o conteúdo, o preenchimento e a borda. O espaço adicional do preenchimento e da borda é subtraído do espaço destinado ao conteúdo.

| VALOR | COMPORTAMENTO |
|-------|---------------|
| Content-box | Largura/altura definidas referem-se apenas ao conteúdo; padding e border são adicionados ao tamanho total. |
| Border-box | Largura/altura definidas incluem conteúdo, padding e border; o conteúdo se ajusta para caber no espaço restante. |

- Exemplo de comparação:
```css
/* Content-box (padrão) */
.elemento1 {
  width: 200px;
  padding: 25px;
  border: 5px solid black;
  box-sizing: content-box;
}
/* Border-box */
.elemento2 {
  width: 200px;
  padding: 25px;
  border: 5px solid black;
  box-sizing: border-box;
}
```
- Explicação:
  - No content-box: o conteúdo tem 200px de largura, mas o tamanho total será 200px + 50px (padding) + 10px (borda) = 260px.
  - No border-box: o tamanho total é 200px, sendo que o conteúdo terá 200px - 50px (padding) - 10px (borda) = 140px.

> [!TIP] DICAS:
> - O border-box é amplamente utilizado para facilitar o cálculo de layouts, pois o tamanho definido já inclui padding e border.
> - A propriedade box-sizing pode ser aplicada globalmente com `* { box-sizing: border-box; }` para tornar o comportamento mais previsível.

# CSS3 - Herança e Especificidade

## 1. Herança
- A herança é um mecanismo pelo qual as propriedades de estilo aplicadas a um elemento são transmitidas aos seus elementos filhos.
- Nem todas as propriedades são herdadas (ex.: margin, padding, border não são herdadas automaticamente).
- Muitas propriedades CSS são passadas para os elementos filhos.

### 1.1 Exemplo Prático de Herança
- Estrutura HTML:
  - Uma div principal contém um h1, um p, e uma div interna.
  - A div interna contém um h2 e outro p.
- Estilos aplicados:
  - Todos os elementos p recebem a cor azul.
  - O elemento h1 recebe a fonte Arial.
  - A div interna (classe sub-container) define que todo h2 dentro dela receberá a cor verde.
- Resultado:
  - O título principal (h1) tem a fonte Arial.
  - Ambos os parágrafos (p) têm a cor azul (herdada da regra geral para p).
  - O subtítulo (h2) tem a cor verde (especificado pela classe da div interna).

> [!TIP] DICAS:
> - A herança ajuda a evitar repetição de código, mas é importante lembrar que nem todas as propriedades são herdadas.
> - Para forçar a herança de uma propriedade que não é herdada naturalmente, use o valor inherit.

## 2. Especificidade
- A especificidade refere-se à prioridade de uma regra de estilo em relação a outras regras.
- Quando duas ou mais regras afetam o mesmo elemento, a regra com maior especificidade tem precedência.
- A ordem de prioridade define qual estilo será aplicado quando há conflitos.

### 2.1 Ordem de Especificidade (Maior para Menor)
- Lista de prioridade:
  - important: propriedade CSS que sobrescreve qualquer outra regra, independentemente da especificidade;
  - Estilos inline (ex.: style="color: red;") – valor 1000;
  - IDs (ex.: #identificador) – valor 100;
  - Classes (.classe), pseudo-classes (:hover) e atributos (type="text") – valor 10;
  - Elementos (div, p, h1, etc.) – valor 1;
  - Universal (*) – valor 0;
  - Herança – não possui especificidade própria.

### 2.2 Exemplo Prático de Especificidade
- Código HTML:
  ```
  <div id="header" class="header"> Conteúdo do cabeçalho </div>
  ```
- Regras CSS:
  - #header { background-color: blue; } → especificidade 100.
  - .header { background-color: red; } → especificidade 10.
  - div { background-color: green; } → especificidade 1.
- Resultado: A cor de fundo será azul, pois o ID tem a maior especificidade.

> [!CAUTION] OBSERVAÇÃO:
> - A regra important deve ser usada com moderação, pois pode dificultar a manutenção do código.
> - O universal (*) tem a menor especificidade e é útil para definir estilos padrão, mas pode ser sobrescrito por qualquer outra regra.

## 3. Propriedades Especiais de CSS
- A tabela a seguir apresenta propriedades que controlam herança e valores padrão:

| PROPRIEDADE | DESCRIÇÃO | EXEMPLO |
|-------------|-----------|---------|
| inherit | Herda o estilo do elemento pai | pai { color: blue; } filho { color: inherit; } |
| initial | Define a propriedade de um elemento como a sua padrão | .elemento { color: initial; } |
| unset | Remove estilos, deixando o elemento como inherit ou initial | .elemento { color: unset; } |
| currentcolor | Aplica a cor de texto atual a outras propriedades | .elemento { border: 2px solid currentColor; } |
| all | Altera todas as propriedades de um elemento de uma só vez | .elemento { all: unset; } |

### 3.1 Explicação das Propriedades
- inherit: faz o elemento herdar o valor da propriedade do elemento pai.
- initial: retorna a propriedade ao seu valor padrão definido pelo navegador.
- unset: comporta-se como inherit se a propriedade for herdável; caso contrário, como initial.
- currentColor: utiliza a cor do texto do elemento para outras propriedades (ex.: borda, sombra).
- all: aplica um dos valores (inherit, initial, unset) a todas as propriedades do elemento.

> [!TIP] DICAS:
> - O uso de initial é comum para resetar estilos específicos.
> - O all é útil para desfazer todos os estilos aplicados anteriormente a um elemento.

## 4. Barra de Navegação Horizontal
- Barra de navegação horizontal exibe links na parte superior da página.
- Geralmente construída com listas não ordenadas (ul) e estilizada com CSS.
- Exemplo de HTML:
  ```
  <nav>
    <ul>
      <li><a href="#">Início</a></li>
      <li><a href="#">Sobre</a></li>
      <li><a href="#">Serviços</a></li>
      <li><a href="#">Contato</a></li>
    </ul>
  </nav>
  ```

### 4.1 Estilização CSS para Barra Horizontal
- Para os itens da lista (li): display: inline; para alinhar horizontalmente.
- Para os links (a): display: inline-block; para permitir definir largura e altura.
- Demais estilos:
  - padding: espaçamento interno;
  - text-decoration: none; para remover sublinhado;
  - transition: para efeito de suavidade ao passar o mouse;
  - a:hover: define mudança de cor de fundo ao passar o mouse.

> [!TIP] DICAS:
> - O display: inline-block combina características de inline e block, permitindo alinhamento horizontal com controle de tamanho.

## 5. Barra de Navegação Vertical
- Barra de navegação vertical exibe links em uma orientação vertical, geralmente na lateral da página.
- Estrutura HTML similar à barra horizontal, mas com estilização diferente.

### 5.1 Estilização CSS para Barra Vertical
- Para os itens da lista (li): aplica-se espaçamento inferior para separar os itens.
- Para os links (a): display: block; para ocupar toda a largura disponível e quebrar linha.
- Demais estilos:
  - padding: espaçamento interno;
  - demais propriedades semelhantes à barra horizontal.

> [!CAUTION] OBSERVAÇÃO:
> - No display: block, cada link ocupa a largura total do elemento pai e fica em uma linha separada.
> - O comportamento block é adequado para menus laterais e listas de navegação vertical.

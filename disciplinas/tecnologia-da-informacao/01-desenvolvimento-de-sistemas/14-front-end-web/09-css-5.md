# CSS3 – Abas e Layouts Líquidos

## 1. Abas
- As abas são uma maneira de organizar o conteúdo de uma página da web.
- Cada vez que o usuário clicar em uma seção (ex.: "Tab 1", "Tab 2" ou "Tab 3"), terá um conteúdo diferente exibido.
- Exemplo prático: site de produtos de uma empresa onde o usuário clica em uma barra fixa e alterna entre as categorias de produtos.

### 1.1 Estrutura do Código das Abas
- A implementação das abas envolve três camadas:
  - HTML (estrutura);
  - CSS (estilização);
  - JavaScript (dinamicidade).

### 1.2 HTML das Abas
- Uma `div` com a classe `tab` comporta três botões, cada um representando uma aba.
- Cada botão possui a classe `tablinks` e o evento `onclick` que chama a função `openTab(event, 'TabX')`.
- Três `divs` com `id` específico (`Tab1`, `Tab2`, `Tab3`) e classe `tabcontent`, contendo um subtítulo (`h3`) e um parágrafo (`p`).

```
<div class="tab">
  <button class="tablinks" onclick="openTab(event, 'Tab1')">Tab 1</button>
  <button class="tablinks" onclick="openTab(event, 'Tab2')">Tab 2</button>
  <button class="tablinks" onclick="openTab(event, 'Tab3')">Tab 3</button>
</div>

<div id="Tab1" class="tabcontent">
  <h3>Tab 1</h3>
  <p>Conteúdo da Tab 1.</p>
</div>

<div id="Tab2" class="tabcontent">
  <h3>Tab 2</h3>
  <p>Conteúdo da Tab 2.</p>
</div>

<div id="Tab3" class="tabcontent">
  <h3>Tab 3</h3>
  <p>Conteúdo da Tab 3.</p>
</div>
```

### 1.3 CSS das Abas
- A classe `.tab` define a estilização geral dos botões.
- Os botões herdam `background-color: #f1f1f1` do elemento-pai.
- Não há borda, mas há `padding`.
- Efeito `hover` altera a cor do botão quando o mouse passa por cima (cinza mais escuro).
- A classe `.active` escurece ainda mais a cor do botão quando clicado.
- A classe `.tabcontent` possui `display: none`, ocultando todo o conteúdo por padrão.

> [!CAUTION] OBSERVAÇÃO:
> - Todas as abas começam invisíveis (`display: none`). Apenas ao clicar em uma aba seu conteúdo é exibido.

### 1.4 JavaScript das Abas
- O JavaScript adiciona a dinamicidade ao sistema.
- Etapas do código:
  - Oculta todo o conteúdo das abas removendo a classe `active` de todos os botões.
  - Define `display: none` para todo o conteúdo.
  - Remove a classe `active` de todos os elementos com classe `tablinks` (botões).
  - Exibe o conteúdo da aba selecionada com `display: block`.
  - Adiciona a classe `active` ao botão clicado (via `currentTarget`).

> [!TIP] DICAS:
> - O evento `onclick` dispara a função `openTab` passando o evento e o id da aba.
> - O `currentTarget` refere-se ao botão que está sendo clicado no momento.

## 2. Tamanhos Fixos
- Definição: forma de definir tamanhos de elementos que se mantêm com a mesma altura e largura independentemente do dispositivo, medidos em pixels (px).
- Características:
  - Não se ajustam à tela do usuário.
  - Podem causar corte de conteúdo em dispositivos menores (celular).
  - Não são responsivos.

> [!CAUTION] OBSERVAÇÃO:
> - Tamanhos fixos em pixels (px) não se adaptam a diferentes resoluções. Se o site for acessado em um celular, o conteúdo pode ser cortado.

- Exemplo:
  - Classe `container` com `width: 300px`.
  - Ao reduzir a tela, o contêiner não redimensiona e pode sumir parcialmente.

```
.container {
  width: 300px;
}
```

## 3. Layouts Líquidos
- Definição: técnica de design web que permite que as páginas se ajustem e se adaptem ao tamanho da tela do dispositivo do usuário.
- Utilizam unidades de medida relativas em CSS.

### 3.1 Percentuais (%)
- Os elementos se ajustam proporcionalmente ao tamanho do elemento-pai.
- Exemplo de estrutura:
  - Classe `container`: elemento-pai com largura de 80% da tela.
  - Classe `sidebar`: flutua à esquerda com 25% da largura do container.
  - Classe `content`: flutua à direita com 75% da largura do container.

```css
.container {
  width: 80%;
  margin: 0 auto; /* Centraliza o container */
}
.sidebar {
  float: left;
  width: 25%;
  background-color: lightblue;
}
.content {
  float: right;
  width: 75%;
  background-color: lightcoral;
}
```

> [!TIP] DICAS:
> - O container sempre ocupará 80% da página, mantendo as bordas laterais.
> - A sidebar e o conteúdo principal mantêm suas proporções (25% e 75%) independentemente do redimensionamento.

### 3.2 Viewport Units (vw/vh)
- Definição: unidades que dimensionam elementos com base no tamanho da área visível do site no dispositivo (viewport).
- `vw`: 1% da largura da viewport.
- `vh`: 1% da altura da viewport.
- Exemplo:
  - Classe `header` com `width: 100vw` (100% da largura da tela) e `height: 20vh` (20% da altura da tela).

```css
.header {
  width: 100vw;
  height: 20vh;
  background-color: lightblue;
}
```

### 3.3 Rem
- Definição: unidade relativa ao tamanho da fonte do elemento-raiz do documento (`<html>`).
- Não utiliza o elemento-pai como referência, mas sim o elemento-raiz.
- Exemplo:
  - Tamanho da fonte base (`html`) definido como `16px`.
  - Classe `box` com `width: 10rem` (10 × 16px = 160px) e `height: 5rem` (5 × 16px = 80px).

```css
html {
  font-size: 16px; /* Define o tamanho base da fonte */
}
.box {
  width: 10rem; /* 10rem = 160px */
  height: 5rem; /* 5rem = 80px */
  background-color: lightskyblue;
  text-align: center;
  line-height: 5rem; /* Centraliza o texto verticalmente */
}
```

> [!CAUTION] OBSERVAÇÃO:
> - A unidade `rem` é similar ao `em`, mas a diferença é que `rem` referencia o elemento-raiz (`<html>`), enquanto `em` referencia o elemento-pai.

### Tabela de Unidades de Medida Relativas
| UNIDADE | DESCRIÇÃO | REFERÊNCIA |
|---------|-----------|------------|
| % | Percentual | Elemento-pai |
| vw | Viewport width | 1% da largura da viewport |
| vh | Viewport height | 1% da altura da viewport |
| rem | Root em | Elemento-raiz (html) |

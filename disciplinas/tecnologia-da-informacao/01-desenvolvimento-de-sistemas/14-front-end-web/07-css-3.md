# CSS3 - Elementos Flutuantes e Posicionamento

## 1. Elementos Flutuantes
- A propriedade `float` é utilizada para deslocar elementos para a esquerda ou direita do container, permitindo que outros elementos fluam ao seu redor.
- Valores possíveis: `left`, `right` ou `none`.

> [!TIP] DICAS:
> - O `float` é uma técnica mais antiga de estruturação de páginas, mas ainda é cobrada em concursos.

### 1.1 Problema do Container e Elementos Flutuantes
- Por padrão, uma `div` ocupa toda a largura disponível do container, mesmo que seu conteúdo seja menor.
- Quando elementos flutuantes são inseridos dentro de um container, eles podem "sair" do container ao redimensionar a página.
- Exemplo: imagens e linhas que deveriam ficar dentro do container cinza podem ultrapassá-lo.

### 1.2 Soluções para Conter Elementos Flutuantes

#### 1.2.1 Display: Flow-Root
- Propriedade que faz com que a altura dos elementos flutuantes internos seja automaticamente reconhecida.
- O container pai reconhece automaticamente a altura dos elementos flutuantes internos.
- Exemplo de código:
```css
.container {
  display: flow-root;
  background-color: #f8f8f8;
  margin: 10px;
  padding: 10px;
}
```
- Funciona com uma única linha de código, independentemente do tamanho da tela.

#### 1.2.2 Clearfix
- Utiliza um pseudoelemento para limpar os floats e garantir que o container pai se expanda adequadamente.
- Exemplo de código:
```css
.clearfix:after {
  content: "";
  display: block;
  clear: both;
}
```
- O pseudoelemento `:after` insere um elemento invisível após todos os elementos do container.
- O `content: "";` é obrigatório, pois sem conteúdo o navegador não reconhece o elemento.
- O `clear: both;` garante que não haja elementos flutuantes nem à esquerda nem à direita.

> [!CAUTION] OBSERVAÇÃO:
> - O clearfix utiliza 4 parâmetros para fazer o mesmo que o `display: flow-root;` realiza em uma única linha.
> - O `content: "";` é essencial, mesmo estando vazio, para que o navegador reconheça o pseudoelemento.

## 2. Posicionamento
- O posicionamento é um conceito fundamental para controlar a localização dos elementos na página.
- Propriedade: `position` com valores: `static`, `relative`, `absolute`, `fixed` ou `sticky`.

### 2.1 Static
- Valor padrão dos elementos.
- Os elementos são posicionados de acordo com o fluxo normal do documento.
- Exemplo: "Eu sou um elemento com posição estática. Eu sigo o fluxo normal do documento."
- Utilizado principalmente para redefinir um padrão (ex.: quando um elemento estava como `fixed` e deseja-se que passe a ser `static`).

> [!TIP] DICAS:
> - O `static` pode ser omitido, a menos que seja necessário redefinir um posicionamento anterior.

### 2.2 Relative
- O elemento é posicionado em comparação à sua posição normal no fluxo do documento.
- Exemplo de código:
```css
.relative {
  position: relative;
  top: 20px;
  left: 40px;
  background-color: lightblue;
  width: 200px;
  height: 100px;
}
```
- `top: 20px;` ⟶ desloca o elemento 20px para baixo em relação à sua posição original.
- `left: 40px;` ⟶ desloca o elemento 40px para a direita em relação à sua posição original.

> [!TIP] DICAS:
> - O `relative` leva em consideração a posição original do elemento no fluxo normal do documento.

### 2.3 Absolute
- O elemento é removido do fluxo normal do documento.
- Posicionado em relação ao seu container pai mais próximo que tenha posição não estática (`relative`, `absolute`, `fixed` ou `sticky`).
- Exemplo de código:
```css
.container {
  position: relative;
  height: 200px;
  width: 400px;
  background-color: lightgray;
}
.absolute {
  position: absolute;
  top: 10px;
  right: 10px;
  background-color: lightgreen;
  width: 100px;
  height: 100px;
}
```
- O elemento com `absolute` é retirado da página e posicionado sobre o container pai.

> [!CAUTION] OBSERVAÇÃO:
> - O container pai deve ter `position: relative;` para que o elemento `absolute` seja posicionado em relação a ele.
> - Se não houver container pai com posição não estática, o elemento será posicionado em relação ao `body`.

### 2.4 Fixed
- O elemento é fixado na tela, permanecendo visível durante a rolagem da página.
- Exemplo: menus fixos ou barras de navegação que acompanham o usuário.

### 2.5 Sticky
- O elemento é tratado como `relative` até que seu ponto de deslocamento dentro do container de visualização seja atingido.
- A partir desse ponto, comporta-se como `fixed`.
- Exemplo: elementos que sobem até o topo da tela e ficam fixos durante a rolagem.

> [!TIP] DICAS:
> - O elemento `sticky` irá subir até onde for possível, sem sair da página.

## 3. Z-Index
- Controla a ordem de empilhamento dos elementos em uma página web.
- O "z" refere-se ao eixo Z (perpendicular à tela), ou seja, profundidade.
- Quanto maior o valor do `z-index`, mais à frente dos outros elementos ele ficará.
- Pode apresentar valores negativos.

> [!TIP] DICAS:
> - O `z-index` é utilizado para definir ou mudar a ordem de sobreposição dos elementos.

## 4. Formatação de Links
- Define a aparência do link com base na ação do usuário.
- Observação: `href="#"` indica que o link aponta para o topo da página atual; é um fragmento de URL vazio usado para ativar comportamentos sem redirecionar.

### 4.1 Link Não Visitado (a:link)
- Define a aparência dos links antes de serem visitados.
- Exemplo:
```css
a:link {
  color: blue;
  text-decoration: underline;
}
```

### 4.2 Link Visitado (a:visited)
- Define a aparência dos links após serem visitados.
- Exemplo:
```css
a:visited {
  color: purple;
}
```

### 4.3 Hover (a:hover)
- Define a aparência dos links quando o cursor do mouse está sobre eles.
- Exemplo:
```css
a:hover {
  color: red;
}
```

> [!CAUTION] OBSERVAÇÃO:
> - O `:hover` pode ser utilizado em outros elementos, não apenas em links, para alterar aparência ao passar o mouse.

### 4.4 Foco (a:focus)
- Define a aparência dos links quando estão focados (ex.: acessados por teclado).
- Exemplo:
```css
a:focus {
  outline: 2px solid green;
}
```

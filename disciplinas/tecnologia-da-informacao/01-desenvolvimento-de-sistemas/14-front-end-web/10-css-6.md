# CSS3 - Recursos Especiais

## 1. Normalize CSS e Reset CSS
- O "reset CSS" redefine todos os estilos, uniformizando o visual das tags.
- O "normalize CSS" ajusta os estilos para uma visualização mais padronizada entre navegadores.
- A escolha entre eles depende da necessidade de uniformidade ou personalização da estilização.
- Exemplo: títulos terão o mesmo tamanho em todos os navegadores com reset, enquanto o normalize mantém características padrão ajustadas.

### 1.1 Reset CSS
- Uniformiza todos os estilos, resultando em uma formatação idêntica para todos os elementos.
- Remove todas as formatações padrão dos navegadores.
- Útil quando se deseja controle total sobre a estilização a partir do zero.

### 1.2 Normalize CSS
- Ajusta os estilos para uma visualização mais consistente em diferentes navegadores.
- Não sobrescreve todas as propriedades, apenas adequa os pontos diferentes.
- Mantém a usabilidade e acessibilidade dos elementos.

> [!TIP] DICAS: 
> - Reset CSS é mais agressivo e remove todas as estilizações padrão.
> - Normalize CSS é mais sutil e preserva a semântica dos elementos.
> - A escolha entre reset e normalize depende do nível de controle desejado.

## 2. Cantos Arredondados
- Utilizados para suavizar a aparência de botões, imagens e outros elementos.
- Propriedade CSS: `border-radius`.
- Permite definir um raio de arredondamento para suavizar as bordas.
- Pode ser ajustado de diversas formas, como em caixas retangulares, caixas irregulares e círculos.

### 2.1 Aplicações Práticas
- Ao definir uma borda de 15px, a curvatura das bordas torna-se mais suave.
- Para criar círculos, definir o arredondamento de 50%.
- É possível especificar o raio de curvatura de cada canto da caixa individualmente.
- Amplamente utilizado para melhorar a aparência de botões e imagens.

### 2.2 Sintaxe
```css
img {
  border-radius: 10px;
}
```

> [!CAUTION] OBSERVAÇÃO: 
> - A propriedade border-radius aplica borda arredondada, não sombra ou transição.
> - Valores acima de 50% resultam em formas ovais ou circulares.

## 3. Sombras
- Técnica utilizada para adicionar profundidade ao design ou destacar elementos.
- Propriedades: `box-shadow` para caixas e `text-shadow` para textos.
- Evita a necessidade de adicionar imagens adicionais para criar efeitos de sombra.
- Possível direcionar a sombra horizontal e verticalmente, definindo intensidade, desfoque e dispersão.

### 3.1 Box-Shadow
- Aplicada a elementos que não são textos.
- Sintaxe: `box-shadow: x-offset y-offset blur-radius spread-radius color;`.
- Exemplo: `box-shadow: 10px 10px 20px 0 rgba(0, 0, 0, 0.5);`.

### 3.2 Text-Shadow
- Aplicada a textos.
- Sintaxe: `text-shadow: x-offset y-offset blur-radius color;`.
- Exemplo: `text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);`.

```css
.shadow-box {
  width: 200px;
  height: 200px;
  background-color: #2196F3;
  margin: 20px;
  box-shadow: 10px 10px 20px 0 rgba(0, 0, 0, 0.5);
}

.shadow-text {
  font-size: 24px;
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
}
```

> [!CAUTION] OBSERVAÇÃO: 
> - Propriedades como shadow-effect, element-shadow e box-effect não existem no CSS.
> - A estilização com sombras em elementos que não são textos é feita com box-shadow.

## 4. Animações
- Recurso importante para adicionar dinamismo a elementos em uma página web.
- A animação não segue um movimento linear, mas sim uma aceleração e desaceleração.
- Propriedade: `animation`.
- Utiliza `@keyframes` para definir os estados da animação.

### 4.1 Propriedades da Animação
- `animation-name`: define o nome da animação.
- `animation-duration`: define a duração da animação.
- `animation-iteration-count`: define o número de repetições.
- `animation-timing-function`: define o padrão de aceleração da animação.
- Exemplo: `animation: exemplo 2s infinite;`.

### 4.2 @Keyframes
- Regra CSS que define as propriedades que participarão da animação.
- Estabelece valores iniciais, intermediários e finais.
- Exemplo:
```css
@keyframes exemplo {
  0% { left: 0px; }
  50% { left: 100px; }
  100% { left: 200px; }
}
```

> [!TIP] DICAS: 
> - A regra que define as propriedades da animação é @keyframes.
> - As animações acontecem independentemente, sem necessidade de gatilho.

## 5. Transições
- Técnica utilizada para adicionar efeitos visuais a elementos durante mudanças de estado.
- Necessitam de um gatilho para ocorrerem (ex: hover).
- Propriedade: `transition`.
- Especifica qual propriedade será alterada, o tempo que a transição levará e o tipo de transição.

### 5.1 Sintaxe da Transição
```css
.transition-box {
  width: 100px;
  height: 100px;
  background-color: blue;
  transition: background-color 1s linear;
}

.transition-box:hover {
  background-color: red;
}
```

### 5.2 Propriedades da Transição
- `transition-property`: define qual propriedade será alterada.
- `transition-duration`: define a duração da transição.
- `transition-timing-function`: define o tipo de transição (linear, ease, etc.).
- `transition-delay`: define o atraso antes de iniciar a transição.

> [!CAUTION] OBSERVAÇÃO: 
> - A principal diferença entre transições e animações é que as transições necessitam de um gatilho, enquanto as animações acontecem independentemente.
> - Transições são úteis para elementos como botões, onde uma mudança sutil de estilo pode ser aplicada ao passar o mouse sobre eles.

## 6. Flexbox
- Modelo de layout unidimensional (horizontal ou vertical).
- Permite o alinhamento de itens mesmo quando seus tamanhos são desconhecidos.
- Torna as interfaces de usuário mais interativas, adaptando-se ao tamanho da tela.
- Propriedade: `display: flex` ou `display: inline-flex`.

### 6.1 Propriedades do Contêiner
- `justify-content`: controla o alinhamento horizontal dos elementos.
- `align-items`: controla o alinhamento vertical dos elementos.
- `flex-direction`: define a direção dos elementos (linha ou coluna).
- `flex-wrap`: controla a quebra de linha dos elementos.

### 6.2 Propriedades dos Itens
- `order`: altera a ordem de exibição dos elementos.
- `flex-grow`: controla o dimensionamento dos elementos para ocupar o espaço disponível.
- `align-self`: permite ajustar o alinhamento individual de cada elemento.

### 6.3 Flex-Wrap
- Permite controlar o comportamento de quebra de linha dos elementos.
- `wrap`: os elementos são dispostos em linhas adicionais quando não há mais espaço disponível.
- `wrap-reverse`: a quebra de linha ocorre, mas os elementos são ordenados de forma inversa.

```css
.container {
  display: flex;
  flex-wrap: wrap-reverse;
  width: 100px;
}
```

> [!TIP] DICAS: 
> - O flexbox facilita a distribuição de espaço e alinhamento de itens dentro de um contêiner.
> - Ao usar flex-grow com imagens, deve-se ter cuidado para não distorcê-las.
> - Flexbox é ideal para layouts unidimensionais (linhas ou colunas).

## 7. CSS Grid
- Técnica bidimensional que permite criar layouts mais complexos.
- Define a posição dos elementos nos eixos x e y de forma precisa.
- Útil para layouts responsivos e designs mais rígidos, como páginas de revistas.
- Propriedades: `justify-content` e `align-items` para alinhar horizontal e verticalmente.

### 7.1 Propriedades do CSS Grid
- `grid-template-columns`: define o número e tamanho das colunas.
- `grid-template-rows`: define o número e tamanho das linhas.
- `gap`: define o espaçamento entre os elementos.
- `justify-content`: alinha horizontalmente os elementos no contêiner.
- `align-content`: alinha verticalmente os elementos no contêiner.

### 7.2 Comparação Flexbox vs CSS Grid
- Flexbox: unidimensional, ideal para alinhamento de itens em uma direção.
- CSS Grid: bidimensional, ideal para layouts complexos com linhas e colunas.

| CARACTERÍSTICA | FLEXBOX | CSS GRID |
|----------------|---------|----------|
| Dimensão | Unidimensional | Bidimensional |
| Uso | Alinhamento de itens | Layouts complexos |
| Controle | Direção (linha/coluna) | Posição x e y |
| Aplicação | Menus, barras laterais | Páginas de revistas, dashboards |

> [!TIP] DICAS: 
> - O CSS Grid faz a criação de layouts com larguras fixas.
> - Tanto o Flexbox quanto o CSS Grid são poderosas ferramentas para criar layouts flexíveis e complexos.
> - A escolha entre Flexbox e CSS Grid depende da complexidade do layout desejado.

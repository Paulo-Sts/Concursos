# Engenharia de Software Desenvolvimento Ágil

## 1. Fundamentos do Desenvolvimento Ágil
- Os métodos ágeis são concebidos para a produção rápida de softwares úteis.
- O software não é desenvolvido como uma unidade única, mas sim como uma série de incrementos onde cada um inclui nova funcionalidade.
- Os processos de especificação, projeto e implementação ocorrem de forma intercalada.
- Não existe uma especificação detalhada do sistema e a documentação do projeto é minimizada.
- O desenvolvimento de interfaces de usuário ocorre de forma interativa através de desenhos e posicionamento de ícones.

## 2. Características Principais
- O sistema é disponibilizado através de uma série de versões.
- Usuários finais e stakeholders participam ativamente da especificação e avaliação de cada versão do software.
- Os envolvidos podem propor alterações e novos requisitos para implementação em versões posteriores.
- O documento de requisitos do usuário define apenas as características mais importantes do sistema.

## 3. Principais Métodos Ágeis
- Extreme Programming (XP) ⟶ considerado provavelmente o método mais conhecido;
- Scrum;
- Crystal;
- Desenvolvimento de Software Adaptativo (ASD);
- Desenvolvimento de Sistemas Dinâmicos (DSDM);
- Desenvolvimento Dirigido a Características (FDD);
- Domain-Driven Design (DDD) ⟶ método ágil com foco maior em modelagem.

## 4. Manifesto Ágil
- Surgiu em 2001 a partir da compilação de melhores práticas por diversos profissionais após constantes fracassos em abordagens tradicionais.

### 4.1 Valores do Manifesto
- Indivíduos e interações mais que processos e ferramentas;
- Software em funcionamento mais que documentação abrangente;
- Colaboração com o cliente mais que negociação de contratos;
- Responder a mudanças mais que seguir um plano.

> [!TIP] DICAS: 
> - Ter conhecimento de métodos ágeis fora da cobrança do edital ajuda a eliminar itens errados em questões.
> - Embora existam valores nos itens à direita dos valores do manifesto, os itens à esquerda são mais valorizados.

## 5. Princípios do Manifesto Ágil
- O manifesto é regido por 12 princípios fundamentais que orientam o desenvolvimento.

| NÚMERO | PRINCÍPIO DO MANIFESTO ÁGIL |
|---|---|
| 1 | Satisfazer o cliente através da entrega contínua e adiantada de software com valor agregado |
| 2 | Mudanças nos requisitos são bem-vindas, mesmo tardiamente no desenvolvimento |
| 3 | Entregar frequentemente software funcionando |
| 4 | Pessoas de negócio e desenvolvedores devem trabalhar em conjunto por todo o projeto |
| 5 | Construa projetos em torno de indivíduos motivados |
| 6 | O método mais eficiente e eficaz de transmitir informações é através de conversa face a face |
| 7 | Software funcionando é a medida primária de progresso |
| 8 | Os patrocinadores, desenvolvedores e usuários devem ser capazes de manter um ritmo constante |
| 9 | Contínua atenção à excelência técnica e bom design |
| 10 | Simplicidade é essencial |
| 11 | As melhores arquiteturas, requisitos e designs emergem de equipes auto-organizáveis |
| 12 | Em intervalos regulares, a equipe reflete sobre como se tornar mais eficaz e então refina e ajusta seu comportamento de acordo |

> [!CAUTION] OBSERVAÇÃO: 
> - Modelos tradicionais ainda são interessantes para sistemas críticos de controle de segurança onde a análise completa é essencial.
> - Metodologias ágeis não excluem a documentação; elas apenas dão mais importância ao software em funcionamento.
> - Os princípios que mais caem em prova são o 1, 3, 10 e 11.

# Visualização de Dados 4

## 1. Conceito de Visualização de Dados
- É a etapa final do processo de ciência de dados, na qual se apresenta os dados em um formato visual, como gráficos e tabelas.
- Envolve a representação gráfica por meio de atributos visuais de dados e informações.
- Permite criar narrativas com os dados.
- Utiliza elementos visuais como gráficos e mapas.
- Auxilia na identificação de tendências, outliers e padrões nos dados.

### 1.1 Posição no Fluxo da Ciência de Dados
A visualização de dados é a última etapa do processo, que segue a seguinte ordem:
- Coleta;
- Processamento;
- Modelagem;
- Visualização.

> [!TIP] DICAS:
> - A visualização é a etapa final, mas é essencial para comunicar os resultados de forma eficaz.
> - O gráfico de área, por exemplo, é muito usado em física e química para mostrar que a área derivada é importante.
> - O gráfico de área empilhada é útil quando se tem três grandezas diferentes.
> - O gráfico de velas mostra a variação do valor de ações ao longo do tempo.
> - O gráfico de densidade apresenta uma curva, não uma reta.
> - O histograma mostra a variação dos dados ao longo da frequência.
> - O gráfico de árvore (treemap) é bastante utilizado em carteiras de ações.

## 2. Benefícios da Visualização
- Provoca uma resposta emocional no público.
- Segura a atenção da audiência.
- É mais facilmente compartilhável.
- Facilita comparações entre dados.
- Facilita previsões.
- Favorece a tomada de decisões.
- Abraça tendências emergentes.

## 3. Tendências em Visualização de Dados
- Conteúdo interativo;
- Acessibilidade;
- Integração de dados;
- Colaboração social (a audiência constrói a visualização conforme deseja).

## 5. Tipos de Visualizações

### 5.1 Gráficos

#### 5.1.1 Gráfico de Área
- A área abaixo da linha é preenchida.

#### 5.1.2 Gráfico de Área Empilhada
- Utilizado quando se tem três grandezas diferentes.

#### 5.1.3 Gráfico de Barras
- Representação por barras verticais ou horizontais.

#### 5.1.4 Gráfico de Barras Agrupadas
- Agrupamento de barras para comparação entre categorias.

#### 5.1.5 Gráfico de Velas
- Mostra a variação do valor de ações ao longo do tempo.

#### 5.1.6 Gráfico de Densidade
- Apresenta uma curva, não uma reta.

#### 5.1.7 Histograma
- Mostra a variação dos dados ao longo da frequência.

#### 5.1.8 Gráfico de Linha
- Representação de dados em sequência temporal.

#### 5.1.9 Gráfico de Radar
- Visualização de múltiplas variáveis em um gráfico radial.

#### 5.1.10 Gráfico de Dispersão (Scatter Plot)
- Representação de pontos em um plano cartesiano para mostrar relação entre variáveis.

#### 5.1.11 Gráfico de Barra Flutuante
- Barras que não partem do zero, representando intervalos.

#### 5.1.12 Linha do Tempo
- Representação cronológica de eventos.

#### 5.1.13 Organograma
- Estrutura hierárquica de uma organização.

#### 5.1.14 Gráfico de Gantt
- Representação de cronogramas e prazos de projetos.

#### 5.1.15 Gráfico de Rosca
- Variação do gráfico de pizza com um buraco central.

#### 5.1.16 Gráfico de Matriz de Pontos
- Matriz com pontos representando dados.

#### 5.1.17 Gráfico Pictográfico
- Uso de ícones ou imagens para representar dados.

#### 5.1.18 Gráfico de Pizza
- Representação de proporções em um círculo.

#### 5.1.19 Gráfico de Árvore (Treemap)
- Representação hierárquica em retângulos proporcionais.

#### 5.1.20 Nuvem de Palavra (Word Cloud)
- Representação visual de frequência de palavras.

### 5.2 Mapas e Geográficos

#### 5.2.1 Mapa de Bolhas
- Mapa com bolhas proporcionais a valores.

#### 5.2.2 Mapa Coroplético
- Mapa com áreas coloridas para representar dados regionais.

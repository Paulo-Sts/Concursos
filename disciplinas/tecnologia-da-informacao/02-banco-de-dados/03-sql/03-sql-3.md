# Banco de Dados - Linguagem SQL 3

## 1. Funções de Agregação - COUNT
- O COUNT(*) é uma função de agregação utilizada para contar a quantidade total de registros existentes em uma tabela.
- Diferentemente de um SELECT *, que exige contagem manual, o COUNT(\*) retorna diretamente o número de linhas da relação.
- O uso do alias (AS) permite nomear a coluna resultante, tornando a leitura mais intuitiva. Sem o alias, o cabeçalho exibirá apenas "count" ou similar.

### 1.1 Exemplo de consulta com COUNT
- Para saber quantos produtos existem na tabela Produto, utiliza-se o comando:

```sql
SELECT count(*) as Total FROM Produto
```

- O resultado será uma única coluna chamada "Total" com a quantidade de registros.

> [!TIP] DICAS:
> - O COUNT(*) não exige a especificação de uma coluna, pois conta todas as linhas da tabela, independentemente de valores nulos.

## 2. Funções de Agregação - AVG, SUM, MAX, MIN
- As funções de agregação são utilizadas para realizar cálculos estatísticos sobre conjuntos de dados.
- São comumente aplicadas em conjunto com a cláusula GROUP BY, que permite agrupar os resultados por categorias específicas.

### 2.1 Principais funções de agregação
- AVG: calcula a média aritmética dos valores de uma coluna.
- SUM: retorna a soma total dos valores de uma coluna.
- MAX: retorna o maior valor de uma coluna.
- MIN: retorna o menor valor de uma coluna.

### 2.2 Tabela Produto utilizada nos exemplos
| NOME | CATEGORIA | PRECO |
|------|-----------|-------|
| Café | Mercearia | R$ 8,99 |
| Açúcar | Mercearia | R$ 10,20 |
| Sabão em Pó | Limpeza | R$ 9,90 |
| Vinho | Bebida | R$ 59,90 |
| Refrigerante | Bebida | R$ 7,90 |
| Detergente | Limpeza | R$ 2,90 |

### 2.3 Consulta com GROUP BY e funções de agregação
- Para obter a média, soma, maior e menor preço por categoria, utiliza-se:

```sql
SELECT categoria, AVG(PRECO) as Média, SUM(PRECO) AS Soma,
MAX(Preco) as Maior, MIN(Preco) as Menor
FROM produto
GROUP BY categoria;
```

- A cláusula GROUP BY deve sempre conter a coluna que está sendo agrupada no SELECT. Caso contrário, o comando SQL gerará erro de execução.

### 2.4 Resultado da consulta
| CATEGORIA | MÉDIA | SOMA | MAIOR | MENOR |
|-----------|-------|------|-------|-------|
| Bebida | 33,90 | 67,80 | 59,90 | 7,90 |
| Limpeza | 6,40 | 12,80 | 9,90 | 2,90 |
| Mercearia | 9,59 | 19,19 | 10,20 | 8,99 |

> [!CAUTION] OBSERVAÇÃO:
> - Sempre que o GROUP BY for utilizado, a coluna de agrupamento deve estar presente na lista do SELECT.
> - Essas consultas são úteis para análises comparativas entre categorias, como identificar onde os preços são mais altos ou a média por segmento.

## 3. Cláusula HAVING
- A cláusula HAVING é utilizada para filtrar os resultados de um GROUP BY, aplicando condições sobre os valores agregados.
- Diferente do WHERE, que filtra registros antes do agrupamento, o HAVING atua após o agrupamento, sobre os resultados das funções de agregação.

### 3.1 Sintaxe do HAVING
- A ordem de execução das cláusulas é: WHERE ⟶ GROUP BY ⟶ HAVING.

### 3.2 Exemplo de consulta com HAVING
- Para selecionar apenas as categorias cuja média de preço seja inferior a 10:

```sql
SELECT categoria, AVG(PRECO) as Média
FROM produto
GROUP BY categoria
HAVING AVG(PRECO) < 10;
```

### 3.3 Resultado da consulta
| CATEGORIA | MÉDIA |
|-----------|-------|
| Mercearia | R$ 9,59 |
| Limpeza | R$ 6,40 |

- A categoria "Bebida" foi excluída do resultado, pois sua média (33,90) não atende à condição imposta pelo HAVING.

> [!TIP] DICAS:
> - O HAVING pode ser combinado com o WHERE para refinar ainda mais os dados antes do agrupamento.

> [!CAUTION] OBSERVAÇÃO:
> - O HAVING é obrigatório quando se deseja filtrar resultados de funções agregadas, pois o WHERE não pode ser utilizado para essa finalidade.

## 4. Comandos de Manipulação de Dados (DML)
- Os comandos INSERT, DELETE e UPDATE são fundamentais para manipular os dados armazenados nas tabelas.
- A prática constante é essencial para evitar erros comuns, como a omissão de cláusulas de condição.

### 4.1 INSERT
- O comando INSERT é utilizado para adicionar novos registros a uma tabela.

#### 4.1.1 Sintaxes do INSERT
- Inserção sem especificar colunas (a ordem deve ser rigorosamente mantida):

```sql
INSERT INTO nome_tabela
VALUES (V1, V2, ..., Vn);
```

- Inserção com especificação de colunas (a ordem não precisa ser mantida):

```sql
INSERT INTO nome_tabela (A1, A2, ..., An)
VALUES (V1, V2, ..., Vn);
```

- Inserção a partir de uma consulta SELECT:

```sql
INSERT INTO nome_tabela
SELECT *
FROM TABELA
WHERE condicao;
```

#### 4.1.2 Exemplos práticos
- Inserindo um produto sem especificar colunas:

```sql
INSERT INTO PRODUTO
VALUES (1, 'TV LCD 50', 3.500, 'ELETRÔNICOS');
```

- Inserindo um produto especificando apenas algumas colunas:

```sql
INSERT INTO PRODUTO (ID, CATEG, NOME)
VALUES (1, 'ELETRÔNICOS', 'TV LCD 50');
```

- Inserindo dados de outra tabela com filtro:

```sql
INSERT INTO PRODUTO
SELECT * FROM PRODUTO2
WHERE CATEG = 'HIGIENE';
```

> [!CAUTION] OBSERVAÇÃO:
> - Ao utilizar INSERT sem especificar as colunas, a ordem dos valores deve corresponder exatamente à estrutura da tabela.
> - Para valores do tipo CHAR ou VARCHAR, é obrigatório o uso de aspas simples. Aspas duplas podem não ser reconhecidas por alguns SGBDs.
> - Recomenda-se sempre especificar as colunas para evitar erros futuros, como a adição de novos campos à tabela.

### 4.2 DELETE
- O comando DELETE é utilizado para remover registros de uma tabela.

#### 4.2.1 Sintaxe do DELETE
```sql
DELETE FROM nome_tabela
WHERE PREDICADO;
```

#### 4.2.2 Exemplos práticos
- Excluir produtos com preço nulo:

```sql
DELETE FROM PRODUTO WHERE PRECO IS NULL;
```

- Excluir todos os produtos (sem condição):

```sql
DELETE FROM PRODUTO;
```

> [!CAUTION] OBSERVAÇÃO:
> - A omissão da cláusula WHERE resultará na exclusão de todos os registros da tabela.
> - O uso do DELETE sem condição é extremamente perigoso e deve ser evitado, a menos que a exclusão total seja intencional.

### 4.3 UPDATE
- O comando UPDATE é utilizado para modificar registros existentes em uma tabela.

#### 4.3.1 Sintaxe do UPDATE
```sql
UPDATE nome_tabela
SET coluna1 = valor1, coluna2 = valor2, ..., colunaN = valorN
WHERE PREDICADO;
```

#### 4.3.2 Exemplos práticos
- Aplicar reajuste de 10% em todos os produtos:

```sql
UPDATE PRODUTO
SET PRECO = PRECO * 1.1;
```

- Aplicar reajuste de 10% apenas nos produtos da categoria "Limpeza":

```sql
UPDATE PRODUTO
SET PRECO = PRECO * 1.1
WHERE CATEGORIA = 'LIMPEZA';
```

> [!CAUTION] OBSERVAÇÃO:
> - A ausência da cláusula WHERE no UPDATE aplica a alteração a todos os registros da tabela, o que pode comprometer a integridade dos dados.
> - Em SGBDs modernos, como algumas versões do MySQL, é solicitada uma confirmação antes de executar comandos perigosos, mas isso não substitui a atenção do usuário.
> - Erros em comandos UPDATE podem ser extremamente críticos, especialmente em ambientes corporativos, como instituições bancárias.

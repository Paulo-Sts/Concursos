# Conceitos de Internet e Intranet 4

## 1. Elementos de Navegação e Interação Digital
- Link ou hyperlink consiste em um elemento clicável que conecta uma página da web a outra, seja no mesmo site ou em sites distintos.
- Funciona como uma ponte digital entre informações, permitindo a navegação com apenas um clique.
- Não leva obrigatoriamente de um local da internet para outro, podendo direcionar também para conteúdos dentro de uma intranet.
- Pode ser representado por um vídeo, uma imagem ou um texto.
- Avatar é a representação visual de uma pessoa em ambientes digitais, como redes sociais, jogos on-line ou aplicativos de mensagens.
- Pode apresentar-se de forma estática ou animada.
- Hashtag é uma palavra ou expressão antecedida pelo símbolo # utilizada para categorizar conteúdos e facilitar a descoberta de temas nas redes sociais.
- Influencer refere-se à pessoa que cria conteúdo e possui o poder de influenciar comportamentos, opiniões ou decisões de seus seguidores.
- Streaming é a tecnologia que permite a reprodução de vídeos, músicas ou transmissões ao vivo em fluxo contínuo.
- Diferencia-se por não exigir o download completo do conteúdo antes do início da reprodução.
- O YouTube é considerado uma das primeiras plataformas de streaming e atualmente funciona como uma rede social de vídeos.

## 2. HTML e Linguagens de Marcação
- HTML (HyperText Markup Language) é a linguagem de marcação de hipertexto utilizada para estruturar conteúdos textuais interpretados pelo navegador.
- Não é classificada como uma linguagem de programação.
- Utiliza marcações denominadas tags, como a tag <title>, que define o título da página exibido no navegador.
- HTML5 representa a versão mais recente, lançada em 2007, trazendo melhorias e a possibilidade de uso de tags dinâmicas.

## 3. URL
- URL é o endereço de rede padronizado no qual se encontra algum recurso de tecnologia ou informática.
- Não é utilizada exclusivamente para páginas web, servindo também para acessar modems ou impressoras de rede.
- Em endereços de URL, espaços em branco podem ser substituídos pelo código %20 para manter a integridade do endereço.

### 3.1 Anatomia e Partes da URL
- A estrutura de uma URL é composta por elementos específicos que identificam o recurso.
- O esquema define a linguagem para a prestação do serviço, como http, https, ftp (transferência de arquivos), mailto (e-mail) ou telnet (acesso remoto).
- O host também é conhecido como domínio.
- A porta não é obrigatória e, quando presente, aparece logo após o host.
- Um exemplo de porta comum é a 80 para o protocolo http e 8080 em servidores específicos.
- O caminho representa diretórios dentro da estrutura de arquivos do servidor.

| PARTE DA URL | DESCRIÇÃO DA FUNÇÃO |
|---|---|
| Esquema ou protocolo | Designa o protocolo de acesso ao objeto |
| Host | Nome que identifica o computador ou endereço ip |
| Porta | Número associado ao protocolo para consumir o serviço |
| Caminho | Identifica o objeto dentro da estrutura do servidor |
| Parâmetros | Informações adicionais para tornar o recurso disponível |
| Fragmento | Referência para uma seção ou subseção de um documento |

### 3.2 Terminações de Domínio
- As terminações identificam a natureza do recurso ou a localização geográfica.

| TERMINAÇÃO | SIGNIFICADO DO DOMÍNIO |
|---|---|
| .com | Comercial |
| .net | Recursos relacionados a redes |
| .gov | Plataformas governamentais |
| .org | Organizações e fundações |
| .br | Identificação do brasil |

> [!CAUTION] OBSERVAÇÃO: 
> - A terminação .com indica que a página é comercial, mas não possui relação obrigatória com o país onde o site está hospedado.

## 4. Conceitos Complementares de Rede

### 4.1 World Wide Web e WHOIS
- WWW (World Wide Web) foi uma padronização internacional obrigatória estabelecida pela W3C, mas atualmente seu uso no endereço é facultativo.
- É possível acessar páginas diretamente pelo domínio, sem o prefixo www.
- WHOIS consiste em um banco de dados que lista todos os domínios registrados.
- É utilizado para fins jurídicos e para pesquisar a disponibilidade de nomes de domínios.

### 4.2 Internet das Coisas e Viabilidade Técnica
- A Internet das Coisas (IoT) permite a conexão de dispositivos do cotidiano à rede.
- Sensores de baixo custo e baixa potência foram as tecnologias que contribuíram decisivamente para a viabilidade prática da IoT.
- Sensores capturam dados do ambiente, como microfones, câmeras ou telas sensíveis ao toque.

> [!TIP] DICAS: 
> - Lembre-se que o protocolo TCP/IP é utilizado tanto na internet quanto na intranet, sendo a diferença básica a restrição de acesso.
> - Link ou hyperlink é o termo técnico para palavras ou imagens que, ao serem clicadas, direcionam para outras páginas.
> - Cookies são pacotes de dados enviados por sites ao navegador para notificar atividades prévias e registrar preferências do usuário.

# Conceitos de Internet e Intranet 3

## 1. Diferença entre Internet e Web
- A internet é a rede mundial de computadores, consistindo em uma estrutura pública que conecta dispositivos em todo o mundo.
- A web representa o conteúdo que pode ser acessado por meio da infraestrutura da internet.
- Estes termos não são sinônimos, sendo a internet a base física e a web a camada de informação.
⟶ Internet ⟶ infraestrutura física;
⟶ Web ⟶ conteúdo acessível.

> [!CAUTION] OBSERVAÇÃO: 
> - É comum a confusão entre os termos, mas para fins de prova, internet é a rede e web é o conteúdo.

## 2. Evolução da Web

### 2.1 Web 1.0
- Denominada web estática, predominante entre as décadas de 1990 e 2000.
- Apresentava conteúdo com baixíssima interatividade, onde o usuário apenas lia ou observava as informações.
- O uso inicial era focado nos meios militar e universitário, com diversas páginas de empresas e instituições ainda em construção.

### 2.2 Web 2.0
- Conhecida como web colaborativa ou participativa, ganhando força a partir dos anos 2000.
- O conteúdo tornou-se dinâmico, atualizado automaticamente e integrado a bancos de dados.
- Marcada pelo surgimento de redes sociais, blogs, chats e a consolidação do comércio eletrônico.

### 2.3 Web 3.0
- Definida como web semântica e inteligente, iniciada por volta de 2010.
- Caracteriza-se pela hiperconectividade 24 horas por dia e pelo acesso facilitado por máquinas.
- Introduziu o uso intensivo de inteligência artificial, machine learning e a personalização de recursos.

### 2.4 Web 4.0
- Conceito em desenvolvimento conhecido como web ubíqua ou simbiótica.
- Foca na integração total entre humanos e máquinas de forma fluida, utilizando internet das coisas e inteligência artificial avançada.
- Utiliza tecnologias como realidade aumentada e big data para proporcionar experiências personalizadas em tempo real.

## 3. Conceitos de Navegação e Conteúdo

### 3.1 Site e Página
- Site é o agrupamento ou conjunto de diversas páginas eletrônicas.
- Página representa um conjunto de informações que podem ser classificadas em dois tipos:
  - Estática: possui conteúdo pré-definido sem alimentação adicional;
  - Dinâmica: o conteúdo é alterado durante a navegação, comum em aplicativos web e portais de notícias.

### 3.2 Home Page e Página Inicial
- Home page é a página padrão de apresentação de um site específico.
- Página inicial é a página configurada pelo usuário no navegador para ser carregada assim que o programa é aberto.

### 3.3 Internet 2 e Backbone
- Internet 2 consiste em uma rede paralela formada por universidades para o desenvolvimento de aplicações avançadas e pesquisas acadêmicas.
- Backbone, ou espinha dorsal, é a estrutura de roteadores de alta velocidade que conecta os continentes e garante a conectividade global da internet.

### 3.4 Cookies e Cache
- Cookies são pequenos arquivos de informação armazenados no computador para registrar preferências e rastrear a navegação do usuário.
- Funcionam como rastros que ajudam o navegador a lembrar preferências, senhas salvas e autocompletar informações.
- Cache refere-se a partes de páginas, como imagens, que são salvas localmente para acelerar o carregamento em acessos futuros.

> [!TIP] DICAS: 
> - Enquanto o cache foca em dar agilidade ao carregamento, os cookies focam em lembrar as preferências do usuário.

### 3.5 Pop-up e Provedor
- Pop-up consiste em uma janela secundária que abre automaticamente durante a navegação, muitas vezes sem solicitação do usuário e interferindo na navegação.
- Provedor é a entidade responsável por intermediar a conexão entre o dispositivo do usuário e a rede mundial de computadores.

## 4. Tecnologias de Rede e Conexão

### 4.1 VPN (Virtual Private Network)
- Trata-se de uma rede virtual privada que estabelece um túnel de comunicação seguro entre dois pontos.
- Utiliza a técnica de tunelamento para garantir que apenas os pontos finais consigam ler as informações trocadas.
- Oferece pilares fundamentais para a comunicação segura:
  - Sessão criptográfica: embaralha os dados para proteção contra interceptação;
  - Autenticação: garante a identidade das partes envolvidas na troca de dados;
  - Anonimato: o tráfego não passa por roteadores locais reconhecidos, permitindo o acesso a servidores internacionais.
- Permite o acesso remoto a intranets, fazendo o computador agir como se estivesse fisicamente no ambiente da rede local da empresa.

### 4.2 Acesso Remoto
- Permite que um utilizador acesse informações e programas em um computador distante por meio de uma ligação de rede.
- Protocolos utilizados para essa finalidade incluem:
  - RDP (antigo Terminal Service);
  - SSH;
  - VNC;
  - Telnet.

### 4.3 IoT (Internet das Coisas)
- Refere-se à rede de dispositivos físicos conectados que se comunicam entre si e com a nuvem.
- Gera um volume massivo de dados, impulsionando o uso de tecnologias de big data para lidar com a velocidade e variedade das informações.

> [!IMPORTANT] DICAS: 
> - Em provas de concursos públicos, a IoT já é considerada por diversas bancas como uma nova categoria de rede de computadores.
